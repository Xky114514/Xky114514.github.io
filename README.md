# AI 录单系统 SuperAdmin 界面复刻

## 使用方式

直接用浏览器打开 `index.html`。项目是纯 HTML、CSS、JavaScript，无需安装依赖或启动服务。

## 复刻范围

页面以 `后台菜单截图` 中的 18 张生产后台截图为视觉基准，并按照《运营迭代需求》补充运营分析能力，覆盖：

- 租户管理：商户管理、额度管理、合同管理、数据看板（试用与转化、额度与合同、使用与效果、系统与配置）。
- 模版库。
- 统计分析：销售分析与采购分析（统计、案例列表、原因分析）、合同统计、Token 用量、语音识别用量。
- 系统设置：信道管理、模型管理、语音识别、桥接管理、原因标签管理。

## 运营迭代能力

- 租户排行增加图片订单数和图片占比，可按图片占比排序；导出数据同步包含这两个字段。
- 案例类型可打开原始文本、图片或文件预览；图片支持多图切换和缩放，加载失败时提供重试提示。
- 案例列表展示原因标签、归因状态、来源、AI 置信度和判断依据；人工可从系统预设标签中搜索、添加或移除标签。
- 原因分析包含完整筛选条件、汇总指标、标签分布、原因趋势、识别率趋势和租户问题排行，并支持租户下钻。
- 数据看板采用统一的租户、异常类型、优先级、当前值、参考值、异常说明、异常时间、负责人和快捷操作结构。

## 交互边界

- 已实现一级菜单、弹出菜单、主页签、子页签和案例分析二级页签切换。
- 地址栏会记录当前界面，刷新及浏览器前进/后退后仍能回到对应页签。
- 业务数据为本地演示数据；排序、导出、预览、租户下钻、归因重试和人工标签调整均在浏览器本地完成，不调用生产接口。

## 文件说明

- `index.html`：全部页面结构和 SVG 图标。
- `styles.css`：后台布局、卡片、表格、状态标签及响应式样式。
- `app.js`：演示数据渲染和只读界面切换。
- `后台菜单截图/`：18 张生产界面参照图。
