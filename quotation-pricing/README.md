# 定价助手 · 观麦口径离线原型 V2.1

更新日期：2026-10-09。本轮将客户价格操作改为一次调价任务一行，保留原规则查询与原生取价约束；产品说明见[需求说明（简版）](docs/requirements-v2.md)。

**本交付使用虚构演示数据，未连接观麦后端或真实 AI。** 应用、保存、角色切换及操作记录仅在当前浏览器演示。演示时间固定为 **2026-09-30 10:00（北京时间）**。

## 业务背景与对象

配送业务需要维护多份报价单；一个客户可以关联多张报价单，一张报价单也可服务多个客户。客户协议价和共享报价单标准价的影响范围不同，必须先明确当前客户、报价单、站点、运营时间和调价范围。

界面中的客户对应门店／收货地址，以 address_id 区分；所属账号用 user_id 关联。结算配置属于客户账号，不属于商品。商品按所属报价单的 SKU 操作，同名或同 SPU 不合并选择或价格。系统“客户协议价”表示价格配置，不代表双方已签署合同。

直接用 Edge 或 Chrome 打开 index.html，样式与脚本均已嵌入，无运行时网络依赖。也可在本目录启动：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8080。用户指定的单文件为上一级目录的 `定价助手-轻量交互版.html`，与本目录 index.html 同步交付。

| 页面 | 用途 |

## 五分钟试用

1. 选择“晨禾食堂 → 日常配送报价单”，保持“客户协议价”。
2. 在采购参考查看 Q1-0001；“选入调价”仅选择商品，不把采购价直接作为售价。
3. 打开按条件调整，选 Q1-0001，选择“随报价单标准价浮动”，按百分比填3；填写2026-09-30至2026-10-07的有效期。
4. 生成预览，核对客户、报价单、商品、标准价、客户适用价、拟调整值及影响。确认后应用，在客户协议调价列表看到一条任务；查看商品明细，再从任务查看关联原规则与操作留痕。
5. 切换报价单标准价，选择“按现标准价调整一次”，对Q1-0004预览上调10%；核对固定协议、浮动协议和普通客户的不同影响，再确认共享范围。
6. 在客户协议调价中手动新建任务：选一个客户和一张报价单，统一有效日期及每日时段，每个商品可分别用固定价、加减值、百分比或倍数；核对后提交。查看历史任务可再次调整，新任务重读当前价格并保留来源。也可从“查看现有价格规则”人工编辑原规则。已关闭／已到期、行情基准、分类继承型 SPU 规则只读；普通 SPU 规则只增改，不移除原有对象。
7. 在报价单定时调价新建任务：选择人民币报价单、未来整点、商品和策略，核对目标价后保存。保存时只安排任务，不立即改价。已保存任务不可更换报价单。
8. 打开 JOB-002 异常详情，复制明确失败商品形成新草稿，重新选择执行时间并核对。原成功项和原任务不自动撤回或重复执行。
9. 在左下角“本地演示 · 使用说明”切换报价员、查看者，体验权限；该切换只是产品演示。

对话可试“Q1-0001按报价单标准价上调3%”。当前仅本地有限语法解析，没有模型调用。商品、基准、范围或日期不明时应补充；同名多规格优先用编码明确。

## 客户协议调价任务怎么理解

- 一次确认对应一条任务。它记录本次商品、计算条件、原价、规则引用及处理结果；实际价格仍由观麦原生规则决定。
- 常规任务只关联一个客户、一张报价单和一组统一生效日期／每日时段；时间不同拆任务。可分批勾选商品，使用“批量设置价格”填写不同方式和数值。
- 对话和按条件调整适合统一策略；“设置客户协议价”先批量填写、再单独调整例外商品，两条路径都形成同类任务记录。
- “配置完成”表示规则已保存，不能推定所有商品当前都按此取价；阶梯、时价及日期仍遵循原系统。
- 已保存客户任务只读。“再次调整”新建草稿、重读当前数据，保存为新任务；失败补处理只带全部明确失败项，成功／跳过项不重复处理。
- 共享、分类、SPU和商品折扣规则保留原编辑方式。任务详情商品列表只是范围展示，不能扁平成逐SKU写入；共享编辑任务保留新旧客户完整范围。
- 没有任务记录的已有规则仍在“查看现有价格规则”中，不凭名称或日期猜测归组。客户任务是本项目新增操作对象，不冒充已有观麦任务接口。
- 客户协议调价没有计划执行时间；提交即配置原规则，未来日期由规则判定适用。报价单定时调价才是预约一次执行的标准价修改。

## 本轮明确的业务边界

- **范围与币种**：首期覆盖普通后台报价，只允许人民币写入；外币、非本站及停用报价单只读。调整不自动重算已创建订单，会员、活动及对外展示价需在原系统核对。
- **权限**：定价主管可看成本、改客户价／共享标准价／任务及看操作记录；报价员不看成本，仅改单客户价格规则；查看者只读。正式权限仍需观麦账号与后端校验，前端演示不构成安全控制。
- **规则与取价**：阶梯价 → 客户协议价 → 时价 → 报价单标准价。阶梯价需数量；日期和每日时段按取价时刻判断，不按未来配送日期预判。固定规则到期后重新按届时有效规则取价，不保证恢复旧价。
- **规则编辑**：保留原报价单、对象类型、计价单位和计算基准。普通 SKU／分类／SPU／适用商品折扣可按原类型演示；SPU 原有对象不可删除。行情基准及分类继承 SPU 只读。关闭／已到期规则不可恢复编辑，需要新规则。
- **折扣口径**：整单折扣作用于适用商品，不自动包含运费等费用；商品 100 元、运费 10 元，商品九折后为 90＋10＝100 元。
- **批量范围**：选择全部匹配固定本次匹配的 SKU 集合，包含其他页；后续新增商品不自动加入。每次最多 5000 项。混合单位不能批量套用相同固定金额。
- **预览有效性**：切换客户／报价单／范围／角色后清空选择，旧预览不可应用；同源另一浏览器页改变数据时，提交前拉取最新数据并重新预览。正式多人并发需服务端实现。
- **时价**：缺少标准价的时价商品不参与比例推算，预览明确跳过并要求确认；可显式设置固定标准价，但时价的实际客户价格仍需系统定价。

## 资料口径

| 资料 | 内容与边界 |
|---|---|
| 采购参考 | 供应商最近采购价、设定损耗率；原接口已转换的单位不再换算。来源展开看供应商、记录日期、类型；超过 7 天提示旧数据，缺日期直接提示。不是完整经营成本，不计算毛利 |
| 商品历史报价 | SKU 历史记录及适用日期，默认近七日，按日期级展示；不是客户成交记录或操作人日志，不补每日价格 |
| 市场行情 | 平台商品、规格、平台单位、平均／最高／最低价与数据日期；超过 3 天提示旧数据，平台关联不保证可比 |
| 客户资料 | 门店、运营时间、账号结算、购买分析和最近订单；半月结为每月 1–15 日／16 日–月末，再按配置延后天数 |
| 价格规则 | 原生客户、范围、计算方式、日期、时段、状态；0关闭、1无效、2未开始、3有效，过期样例状态为0 |
| 操作记录 | 本地人工确认的动作与前后值，用于原型追溯；不是报价快照，不提供自动回滚 |

采购来源与报价单币种不同或缺少可核对的汇率时显示“无法比较”，不把采购金额标成报价单外币。采购超过 7 天、行情超过 3 天仅提示，不自动拦截明确基价的调价。采购来源结构是本地演示适配，正式接入需由采购记录补齐。

购买分析默认演示 2026-09-01 至 2026-09-30、按下单时间，直接展示原统计结果；最近订单单独采用近90天内最近50单，不从该样本重算购买分析。SKU 和客户价按分展示，行情保留平台金额单位，订单与统计按对应来源尺度处理。缺失为“—”，正常零价不当作缺失。系统建议价范围只在商品详情展示，不称 AI 推荐。

## 报价单定时调价与导入

报价单定时调价是**一次执行**，不表示按天重复的计划或观麦另一类周期公式调价。任务名称、报价单、未来整点时间、至少一个商品必填；保存后锁定报价单，换单需新建任务。未开始任务可编辑名称、时间和商品价格；已生效／已结束任务只读。

固定价、加减值、百分比、倍数均按当前标准价计算一次并保存确定目标价。例如标准价5元，上调10%保存目标5.50元；未来执行前标准价变为6元，任务目标仍是5.50元。任务重叠展示先后与重复商品，后续实际写入结果由执行情况决定。

列表移除“执行结果”列，但保留原生状态及异常标识。已生效不保证所有商品成功；有失败明细时，失败表独立按25条分页，可全量复制所有明确失败项至新任务，不只复制当前页；原成功项保留。无失败明细时要求去原系统核查。时间到达不自动变状态，浏览器不执行任务。

导入支持 XLSX 首表、UTF-8／GB18030 CSV、TSV；模板包含商品编码（或SKU）、调整方式、数值、销售单位，也可用目标价列。3代表3%，0.95代表倍率95%。公式与百分比格式单元格需先转成明确数值；不支持旧xls直接读取。

文件内重复、跨报价单、未知商品、单位或原金额校验不符、金额无效时整批拒绝，草稿不变。与已有草稿重复的 SKU 显示更新数量，确认后更新一次。限制为5MB、5000行，XLSX解压20MB。导入仅处理价格字段，不覆盖商品名称、库存等资料。
