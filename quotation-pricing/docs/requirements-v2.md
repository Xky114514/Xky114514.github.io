# 报价助手需求说明（简版）

更新日期：2026-10-10。适用于当前“对话＋列表”原型。数据含义以观麦口径为准，接口对应见[字段对应表](guanmai-fields.md)。

## 1. 目标与范围

帮助报价人员按客户批量调整商品价格，核对采购参考、历史报价及客户资料，并追溯每次调整。

本期交付离线演示原型，包含报价对话、客户协议调价任务、现有价格规则编辑、报价单定时调价及操作记录。使用演示数据，不连接真实 AI、观麦服务或执行队列。演示业务时间固定为 **2026-09-30 10:00，北京时间**。

| 角色 | 可执行操作 |
|---|---|
| 定价主管 | 查看采购参考，管理客户协议调价、共享规则、标准价和计划任务，查看操作记录 |
| 报价员 | 调整单客户价格；不能查看采购成本、修改共享规则及标准价、管理计划任务或查看操作记录 |
| 查看者 | 查看授权资料，不能调价，也不能查看采购成本和操作记录 |

原型角色切换仅用于试用；正式产品沿用企业账号权限，提交时重新校验。

## 2. 对象与页面

客户按门店／收货地址识别，并关联所属客户账号。**一个客户可关联多张报价单，一张报价单可服务多个客户**。商品按“报价单＋SKU”区分，同名商品不合并价格与选择状态。

| 页面／区域 | 作用及主要操作 |
|---|---|
| 顶部与报价单侧栏 | 选择客户、关联报价单和调价范围；持续展示当前上下文。多张报价单时须明确选中一张，默认调整客户协议价 |
| 报价对话 | 输入需求或使用“按条件调整”，选品、设置价格、核对预览后应用演示 |
| 客户与依据 | 用采购参考、商品历史报价、市场行情、客户资料、价格规则五个列表查看相关资料 |
| 规则与调价—客户协议调价 | 一次已确认调整一行，展开后每个商品一行；可新建、再次调整、处理失败项、查看现有价格规则 |
| 规则与调价—报价单定时调价 | 新建一次性预约任务，维护待执行商品和目标价，查看原生状态及异常明细 |
| 操作记录 | 查看操作人、时间、对象、来源及前后值；与商品历史报价分开 |

三种价格的含义：

| 名称 | 含义 |
|---|---|
| 报价单标准价 | 报价单商品的默认售价；原型改用这一名称，观麦原字段不变 |
| 客户协议价 | 针对客户保存的固定价或浮动规则，含有效日期和时段 |
| 客户当前价 | 当前按原取价顺序计算出的只读结果，不是第三个可独立修改的价格 |

例如标准价5元、客户有效固定协议4.80元，未命中阶梯价时，客户当前价是4.80元。

## 3. 使用流程

两类调价都复用“选品—设价—核对”，但修改对象和时间含义不同：

| 对比 | 客户协议调价 | 报价单定时调价 |
|---|---|---|
| 修改对象 | 指定客户的协议规则，标准价不变 | 一张报价单的标准价，可能影响多个关联客户 |
| 时间 | 现在保存规则，按有效期及每日时段参与取价 | 到计划整点执行一次价格修改 |
| 列表状态 | 配置结果；完成不等于此刻已适用 | 执行状态及异常；到时不等于执行成功 |
| 例子 | 晨禾10月白菜协议价4.80元/斤 | 明早8点把报价单白菜标准价改为5.20元/斤 |

**客户协议调价：**选客户与报价单 → 勾选商品 → 批量设置价格（可分批勾选设置） → 填有效期 → 核对预览 → 确认配置，记录为一条任务。

- 同一任务对应一个客户、一张报价单、统一有效日期及每日时段；商品可分别采用不同方式和数值。需要不同有效期时分开建立。
- 确认后保存原生客户价格规则；任务用于记录本次操作。历史明细只读，“再次调整”重新读取当前价格并产生新任务。
- 共享或分类、SPU等范围规则通过原规则编辑入口处理，保留完整范围；不能拆成“只改当前客户”的商品任务。原规则修改也记录本次任务及规则引用。

**标准价即时调整：**主动切换“报价单标准价” → 选商品并设价 → 查看全部关联客户及各自影响 → 确认后修改当前报价单标准价。

**报价单定时调价：**新建任务 → 选报价单和未来整点 → 选品或导入 → 设置各商品目标价 → 核对共享影响 → 保存。只有未开始任务可以修改；保存不会立即改变标准价。

## 4. 字段说明

以下来源资料默认只读，缺失显示“—”。填写字段按表中要求校验；系统编号和历史快照不允许手工覆盖。

### 4.1 选择与搜索

| 字段 | 含义及要求 |
|---|---|
| 客户、报价单 | 调价必选，报价单须与客户关联；仅当前站点启用、受支持的报价单可写 |
| 我要调整 | 客户协议价／报价单标准价，默认客户协议价；标准价操作需主管权限 |
| 搜索、分类 | 按商品名称、编码、规格包含匹配，配合原商品分类；搜索最多100字，空值为全部 |
| 任务商品 | 至少1项、最多5000项；新勾选商品加入任务，取消勾选保留商品及价格，移出任务须点击“移除” |
| 本次勾选、只看任务商品 | 本次勾选决定批量操作范围，支持本页、全部匹配及跨页；只看任务商品是列表筛选，不改变勾选或任务范围 |
| 每页条数 | 商品编辑默认25，可选25／50／100；任务列表、详情和预览每页25 |
| 计算数量 | 读取阶梯价所需的销售数量，正数；不是订单数量或新设阶梯门槛 |

切换客户、报价单、调价范围或角色后清空选品、数量及旧预览。筛选变化回到第一页，分页和搜索不丢失选择。“全部匹配”只包含点击时命中的商品，不自动包含以后新增商品。

### 4.2 客户协议调价与预览

| 字段 | 含义、默认与校验 |
|---|---|
| 任务名称、编号 | 名称1—80字，手动新建必填；对话／条件入口可自动生成后修改。允许重名，以系统编号区分 |
| 报价调整需求 | 1—2000字；描述商品、调整方式和时间，信息不足时补充，不直接写价 |
| 定价方式 | 必选；默认“直接指定客户价格”，也可选“随报价单标准价浮动”“按客户当前价调整一次”；计算参考由方式确定，不再独立选择 |
| 怎样调整、数值 | 直接指定价格时只填新价格；另外两种方式选择百分比／加减金额／倍数并填数值。切换定价方式或调整方式清空数值，避免单位误用 |
| 有效开始、结束日期 | 客户规则必填，开始不得晚于结束，结束不得在演示当前日期之前；两端包含当天 |
| 每日开始、结束时间 | 默认00:00—23:59；当日时段开始≤结束，跨午夜时开始>结束，须明确选择跨午夜 |
| 报价单标准价、客户当前价 | 两列只读，带销售单位和问号说明；不把客户当前价作为独立可修改字段 |
| 本次协议设置 | 列表显示已填入的结果摘要；预览以固定价格或浮动公式为主，浮动的当前计算值仅供核对 |
| 影响客户、前后价 | 共享调整列出全部关联客户，按各自原规则重新取价；关联不代表价格必然变化 |
| 处理情况、原因 | 区分可调整、冲突、失败和跳过；无可调整项不可提交，跳过项须明确确认 |
| 任务处理状态 | 配置完成／部分完成／配置失败，表示本次规则写入情况，不表示此刻价格已经生效 |
| 创建人、时间、来源 | 记录确认人、确认时间及操作入口；再次调整和失败补处理关联原任务 |
| 商品快照、原规则引用 | 详情保存当时名称、编码、规格、单位、前后值、设置方式、逐项结果及规则编号；后续改价不反写历史 |

客户协议调价的输入联动：

| 定价方式 | 必要输入 | 保存含义 |
|---|---|---|
| 直接指定客户价格 | 新价格；无参考价或调整方式选择 | 固定协议价 |
| 随报价单标准价浮动 | 百分比／加减金额／倍数及数值 | 持续随标准价变化的协议规则 |
| 按客户当前价调整一次 | 百分比／加减金额／倍数及数值 | 一次算成固定协议价，以后不跟随标准价变化 |

商品表只显示价格摘要，仅保留“批量设置价格”入口；勾选一个或多个商品都用同一操作，不同价格分批勾选设置。无勾选时按钮置灰，填入只更新勾选商品的草稿。取消勾选保留商品及价格；“移除”或“移除勾选商品”经确认后才移出任务。编辑已有任务及再次调整时默认不勾选商品，导入确认后仅勾选本次导入项。

已填入结果在列表标记“已设置”，取消勾选仍保留。重新打开同批商品时，相同方式、基准和数值自动回显；不同设置显示“多种设置”，明确选择后才能统一修改，未确认前各商品结果不变。覆盖已有不同设置须确认，取消不改原值；新加商品待设置。核对包含全部任务商品，未勾选的待设置商品也不能被忽略。正在填写的设置须填入或取消后才能核对，搜索、分页不缩小勾选范围。

“按条件调整”采用相同定价方式。修改报价单标准价时仅有“直接指定报价单标准价”和“按现标准价调整一次”，均保存确定价格，不提供对自身持续浮动的选项。

### 4.3 客户与依据

| 标签／字段 | 含义与展示要求 |
|---|---|
| 商品资料 | 名称、编码、SKU、规格、所属报价单、销售单位、基本销售单位；详情同时展示商品基本单位、基本单价和阶梯数量档 |
| 供应商最近采购价 | 供应商维度最近采购参考价，按原接口已转换的基本销售单位展示；只保留这一列采购价，无值不取其他采购价代替 |
| 采购来源 | 对应该采购价的供应商、来源类型、记录日期；缺失不猜测，超过7日提示旧数据 |
| 商品设定损耗率 | 商品配置的预计损耗百分比，不是实际损耗重量或完整成本 |
| 选入调价 | 仅把商品选入当前调价范围，不把采购价自动作为售价，也不直接生效 |
| 商品历史报价 | 展示SKU记录销售价、记录基本单价、适用起止日期和当前标准价；默认近7日，按适用区间重叠查询，不补齐每天价格，不视为成交记录 |
| 市场行情 | 最新可用的平台／市场、平台商品、规格、单位、平均价／最高价／最低价及数据日期；保留平台单位，超过3日提示旧数据，不自动判断可比 |
| 客户档案 | 客户名称、编码、门店标识、所属账号、联系人、电话、地址、运营时间 |
| 结算配置 | 展示原生日结、周结、月结、自定义、半月结及对应配置；归属于客户账号，不归属于商品 |
| 客户购买分析 | 原接口订单数、销售额、下单额；默认近30日、按下单日期，可切换收货日期；统计覆盖客户不同报价单 |
| 最近订单 | 近90天内最近50单，按下单时间倒序；列订单号、时间、下单金额、出库金额、商品明细数，不据此推算完整购买分析 |
| 系统建议价范围 | 仅商品详情显示系统已有上下限，不称为AI推荐 |

采购来源和价格受同一成本权限控制。采购与行情的旧数据提示不自动阻止明确标准价的调价；没有演示查询快照时显示无数据，不自行统计或补零。

### 4.4 现有价格规则

| 字段 | 含义与编辑边界 |
|---|---|
| 名称、编号、报价单 | 名称必填1—80字；编号及所属报价单只读，修改保留原编号 |
| 适用客户 | 至少一个与报价单关联的客户；共享修改须核对新旧客户并集，移出客户也计入影响 |
| 对象类型、范围 | 保留原SKU、二级分类、商品上浮、适用商品折扣类型；不能通过编辑改变类型 |
| 计算基准、计价单位 | 原报价单价或原行情基准、销售或基本单位，只读；不得把基本单位锁价改作销售单位 |
| 计算方式、数值 | SKU支持固定价／加减值／倍数；分类支持加减／倍数；SPU支持倍数；适用商品折扣倍率为大于0且不超过1 |
| 有效日期、每日时段 | 与客户协议调价的时间要求相同；限时固定价在有效日期和每日时段内参与原生取价 |
| 开关、原生状态 | 可编辑规则可启用／停用；原状态为关闭、无效、未开始、有效。已关闭、已到期规则只读 |

系统价格规则不等于双方已签署合同。普通SPU规则不能在此删除原有对象；含分类继承或行情基准的特殊规则本期只读，转原系统处理。

### 4.5 报价单定时调价与导入

| 字段 | 含义与要求 |
|---|---|
| 任务名称、编号 | 名称必填1—80字，同报价单内不重复；编号系统生成 |
| 报价单 | 新建必选，保存后锁定；换单需另建任务 |
| 计划执行时间 | 必填、未来整点，北京时间；同报价单同时间不可重复，无结束时间及重复周期 |
| 商品数、定价方式 | 至少1项、最多5000项；直接指定报价单标准价，或按现标准价调整一次（百分比／加减金额／倍数） |
| 标准价、本次价格设置 | 标准价只读；本次设置显示待执行目标价及计算方式。填入时算定目标价，执行时不重新计算；未修改行保留原目标价 |
| 原生状态、异常标识 | 未开始／已生效／已结束，异常在状态旁提示；列表不设“执行结果”列 |
| 失败明细、来源任务 | 展示明确失败商品与原因；可复制全部失败项到新任务，重新确定时间及价格；不重复成功项 |

选品、分批勾选及批量设置的交互同客户协议调价，商品表只读展示摘要。直接指定价格只填金额；按现标准价调整一次才显示百分比／加减金额／倍数，不提供客户当前价或持续浮动选项。切换方式清空数值，填入只改草稿，批量覆盖已有不同设置需确认；新选商品待设置。时价或缺标准价无法按比例计算时，标记“需处理”，可重新勾选该商品，通过批量入口指定价格；全部任务商品设置完成后才能保存。

导入仅属于报价单定时调价，确认后先加入草稿，仍需预览并保存。

| 模板字段 | 填写要求 |
|---|---|
| 商品编码 | 必填并能唯一定位当前报价单商品；也可用SKU列，两列同时填写须一致 |
| 调整方式 | 固定价／加减值／百分比／倍数 |
| 数值 | 与方式配套的普通数字，百分比填3表示3%，倍数填0.95 |
| 销售单位 | 必填，须与商品完全一致，不自动换算 |
| 目标价（可选替代列） | 可替代“调整方式＋数值”；非空时按固定价处理，0有效 |

支持XLSX首张表、CSV、TSV；单文件≤5MB、≤5000行，XLSX解压内容≤20MB。CSV兼容UTF-8和GB18030。公式、百分比格式须先转为明确数值。文件内重复、跨单、单位不符、金额或格式错误均整批拒绝并标明行号；与草稿重复的商品显示更新数量，确认后替换。

## 5. 关键业务规则

1. **取价顺序：阶梯价 → 客户协议价 → 时价 → 报价单标准价。** 阶梯价缺数量不显示确定价，客户协议调价不修改阶梯表；时价未定显示“待定价”，不能当作免费商品。
2. 以客户当前价计算一次性结果时，转为固定价。例如4.80元上调5%为固定5.04元；以标准价上调5%则形成1.05倍规则，随标准价变化。
3. 客户专属调整不改共享标准价。共享标准价调整后，普通客户可能变价、固定协议客户可能不变、浮动协议客户按基准变化。未来日期仅设置规则，不预先承诺未来结算价；不重算已创建订单。
4. 冲突按原生客户、商品范围、日期及规则类型检查，不能凭错开每日时段自动解除日期冲突，也不增加“同客户只能一套规则”的限制。
5. 目标价0—999999.99元，金额最多2位小数；加减金额绝对值不超过999999.99。倍数大于0且≤100，百分比大于-100且≤9900。空值不转0，负结果、无效或越界数字阻断。
6. 界面和导入模板不展示、填写币种；人民币金额显示“元”及对应商品单位。系统仍保留原金额校验，不将外币数值标为元；暂不支持的金额显示“—”，相关报价单只读。SKU价格与订单、行情金额分别按原尺度处理，不统一除以100。
7. 固定价／加减值批量设置要求计价单位一致，不同单位须分批勾选设置；百分比／倍数逐行计算。采购价不重复换算，斤／公斤／箱／包不混加为总重量。目标价演示计算到分，半分取偶数分；真实接入须与原系统舍入口径核验。
8. 标准价计划任务是预约执行一次，不是循环任务，也不自动到期恢复。时间到达不代表成功；同商品不同排期提示覆盖顺序，原生状态不由前端时钟推断。
9. “配置完成”仅表示规则已保存，是否适用仍看时间、客户、范围和原生取价规则。失败补处理只复制全部明确失败项，不受当前搜索或分页影响；再次调整及补处理均新建任务，原历史不变。

## 6. 异常与交互

| 情况 | 处理 |
|---|---|
| 未选客户／报价单、关系失效、越权或报价单只读 | 阻止调价，说明原因；不能借对话绕过权限 |
| 缺少价格、单位、数量或有效期 | 定位缺项并保留草稿；不能用0、默认日期或其他采购价补齐 |
| 冲突、共享规则或无法处理的原生类型 | 显示原因并提供查看原规则入口；共享变更需完整确认，不能静默拆分 |
| 选择含跳过项 | 预览分别计数并说明原因，确认后只提交可调整项；没有可调整项则阻止提交 |
| 旧预览、其他页面已更新数据 | 提交前重新校验，使旧预览失效，要求重新核对；不覆盖新数据 |
| 未保存时关闭或切换 | 询问是否放弃；取消则保留草稿。浏览器刷新不保证恢复未保存内容 |
| 保存失败、结果不明 | 保留输入并显示原因；正式接入先查询结果再决定重试，防止重复写入；本地存储失败明确提示尚未持久保存 |
| 执行异常但没有明细 | 提示去原系统核查，不推断全部成功，不盲目重跑整任务 |
| 搜索无匹配、来源资料缺失 | 显示空态并保留筛选；不伪造数据或补零 |

说明统一用问号Tooltip，支持悬停、键盘和触屏；必须处理的错误、状态、共享影响直接显示。窄屏保留列表，表格在内部横向滚动。

## 7. 验收与实现边界

- 多客户、多报价单及同名SKU切换不串价、不串选择；客户调整只改对应规则，共享标准价影响按各客户重新取价。
- 任务主列表一任务一行，明细逐商品；混合调整方式、再次调整、失败补处理及原规则追溯可走通，历史不会被反写。
- 供应商采购价、来源和缺失值对应正确；不再展示独立“最近采购价”及币种字段；新版四列模板可正常导入。
- 验证三种定价方式的输入联动与保存结果、批量覆盖及移除确认、取消勾选保留价格、分批设置不误改其他商品、阶梯缺数量、时价待定、冲突、限时规则及共享确认。
- 验证300／1000商品的搜索、分页、跨页批选和不同单位；错误导入保持原草稿，合法零值不丢失。
- 权限覆盖列表、详情和对话；未开始任务可改，已执行任务只读；桌面及窄屏可用，Tooltip不遮挡关键操作。

AI负责将自然语言整理为结构化调价草稿、补问缺项和解释预览，人工确认后才应用。当前原型使用有限语法演示，不代表已接入模型。正式开发复用观麦客户、报价单、取价、规则及任务能力，补充客户任务汇总、逐项结果、并发与重复提交控制；权限、金额精度和调度结果需联调验收。
