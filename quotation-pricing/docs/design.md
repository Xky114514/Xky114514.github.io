# 定价助手界面设计说明 · 观麦口径 V2.1

更新日期：2026-10-09。保留“对话＋列表”，按普通后台报价的实际约束重整业务对象、权限、时间、规则和异常处理。产品说明见[需求说明（简版）](requirements-v2.md)，来源口径见[字段对应表](guanmai-fields.md)。

本轮为离线 HTML 原型：虚构数据、固定业务时点2026-09-30 10:00，不连接真实AI、观麦后端或执行队列；本轮不发布GitHub。

## 1. 对象、上下文与权限

| 对象 | 设计 |
|---|---|
| 客户 | 门店／收货地址 address_id，关联所属账号 user_id；账号承载结算配置 |
| 报价单 | 独立保存币种、启用状态、站点和运营时间；客户与报价单多对多 |
| 商品 | 在所属报价单下按SKU区分；同名、同SPU不合并价格或选择 |
| 客户协议调价任务 | 一次已确认客户调整的操作记录，一行一任务；明细每个商品一行，保存后只读 |
| 客户协议价／原生价格规则 | 系统客户价格配置，不等同于已签署合同；决定价格，保留原生对象类型、日期、时段和状态 |
| 报价单定时调价 | 一个报价单、确定目标价、未来整点预约执行一次；不是循环执行 |
| 操作记录 | 本地人工确认动作的过程追溯，与历史报价快照分开 |

顶部持续显示客户、报价单、站点、运营时间和调价范围。客户有多张报价单时必须明确选择；默认调整客户协议价。共享标准价需主动切换。仅本站启用的人民币报价单允许写入，外币和停用报价单只读。

| 演示角色 | 成本 | 单客户规则 | 共享规则／标准价 | 标准价计划任务 | 操作记录 |
|---|---|---|---|---|---|
| 定价主管 | 可看 | 可改 | 可改 | 可管理 | 可看 |
| 报价员 | 不可看 | 可改 | 不可改 | 只读 | 不可看 |
| 查看者 | 不可看 | 不可改 | 不可改 | 只读 | 不可看 |

角色切换只是演示；正式权限由原系统账号授予，并在提交时再次验证。成本在列表、来源与商品详情均隐藏，不能通过对话补出隐藏数据。

## 2. 对话调价及选择

1. 选客户、报价单和“我要调整”的对象。
2. 用文字或按条件调整选SKU，选择定价意图并填写对应数值。固定价不选基准，浮动自动参考标准价，一次调整自动参考客户当前价。
3. 客户规则补充有效日期、每日时段，跨午夜单独选择。
4. 生成预览，查看标准价、客户适用价、拟调整值、跳过项和每位关联客户的实际影响。
5. 核对共享影响及跳过商品后应用演示；客户协议价生成一条客户协议调价任务，记录操作人、对象、前后值及规则引用；标准价直接修改不误记为客户任务。

有限语法解析只整理意图，不自动定价；缺少对象、基准、日期时补充，同名多规格使用编码明确。支持名称／编码／规格、分类、分页、跨页选择、选择本页和全部匹配。全部匹配固定当次SKU集合，后续新增商品不加入；最大5000项。

切换客户、报价单、调价范围或角色清空选择并使旧预览失效。另一同源页面修改本地数据时，提交前加载新数据并重新预览；不静默覆盖。刷新后历史预览只能阅读。正式多人并发仍需服务端版本控制。

## 3. 依据页面

| 标签 | 展示与边界 |
|---|---|
| 采购参考 | 供应商最近采购价、设定损耗率、原单位；来源展开看供应商／记录日期／类型。超过7天提示旧数据；缺日期提示未提供。不是完整成本，选入调价只选商品 |
| 商品历史报价 | SKU历史价格与适用日期，默认近7日，日期级展示；不补每日价格，不当作成交记录或修改人日志 |
| 市场行情 | 平台商品、规格、平台单位、均／高／低价、数据日期；超过3天提示旧数据，关联不保证可比 |
| 客户资料 | 门店、联系人、地址、运营时间、账号结算、原生购买分析与最近订单 |
| 价格规则 | 原生客户、范围、计算方式、日期、每日时段、状态与人工编辑入口 |

采购超过7天、行情超过3天仅提示风险，不禁止明确基价的调价。采购单位已转换时不重复换算；缺汇率或币种不可核对显示无法比较，不把原值标为外币。

购买分析直接采用原接口订单数、销售额、下单额，默认近30日按下单时间；最近订单独立为近90天内最近50单，不能据其推算完整统计。半月结为每月1–15日、16日–月末，再按delay_day延后；周结、月结、自定义按各自原配置展示。

界面和导入模板移除币种项；支持的金额展示“元”及原计价单位，其他金额显示“—”并保持只读，内部仍保留原金额校验。金额按各接口尺度处理；缺失“—”，正常0保留，时价未定展示待定价。系统建议价范围只在详情显示，不包装成AI建议。来源追溯结构属于本地适配，正式需要采购记录补齐。

## 4. 客户协议调价任务、规则编辑与取价

“规则与调价”默认标签为客户协议调价，主列表按一次已确认调整一行，显示名称、客户／报价单、商品数、有效日期、处理状态及操作。任务名搜索和客户／报价单筛选共同生效，每页25条。没有记录显示空态，并保留新建与查看现有价格规则入口。

手动新建一个客户、一张报价单、统一有效日期和每日时段；不同日期拆任务。商品可按名称／编码／规格搜索、分类和跨页选择，商品列表只读展示标准价、客户当前价和本次协议设置；勾选后打开“批量设置价格”，少量例外用“单独设置”。先选直接指定价格／随标准价浮动／按客户当前价调整一次，再展示必要输入；不独立选择计算基准。切换方式清空数值，填入只改草稿，覆盖已有设置需确认，取消保留原值，未填入的编辑阻止进入预览。任务名称1—80个UTF-16单元，允许重名，任务编号唯一；一次最多5000商品。辅助解释收进问号提示，错误直接显示。

详情冻结原价、当时标准价、设置值、商品单位、规则引用与逐项成功／失败／跳过。配置完成不等于当下价格已生效，当前取价仍由原规则决定。“再次调整”重读当前数据生成新草稿、新任务；“处理失败项”只复制全部明确失败商品，搜索和分页不缩小范围，不重复成功项，也不把跳过项自动当失败重跑。历史任务不被新规则更新反写。

“查看现有价格规则”保留原生规则列表，包括没有任务的历史规则。原规则详情SKU可名称／编码／规格搜索，每页25条；从任务进入规则详情可返回原任务。共享、分类、SPU、折扣任务的再次操作转原规则编辑器，不把其范围列表展开成逐SKU写入；共享任务记录新旧客户并集及完整原范围。

原型全量校验常规提交后才统一写入；部分失败仅使用明确的演示样例。真实开发需要新建任务聚合、逐项结果与原规则边界、提交幂等和结果核查，不能据离线成功认为观麦已有客户任务服务。


客户协议价使用固定值、加减值和倍数；百分比转换为倍率。按客户当前价一次计算保存为固定价，按标准价加减／倍数保存为浮动规则。有效期必须明确。

取价顺序：阶梯价 → 客户协议价 → 时价 → 报价单标准价。阶梯价缺数量时不能给确定结果；客户规则不修改阶梯表。时间按实际取价时刻判断，不能把未来配送日期当成未来价格。修改不重算已创建订单，其他会员、活动及对外展示场景回原系统核对。

固定／浮动／普通客户分别展示共享标准价调整后的影响。时价缺基价时比例计算跳过并要求确认；明确设固定标准价不代表时价客户立即有确定售价。

人工编辑保留原编号、报价单、类型、基准与计价单位。多个客户共用的规则只允许完整编辑并确认全部影响，不静默拆分。冲突按客户、商品范围、日期及原生类型检查；错开每日时段不当然解除日期冲突，也不增加“同一客户只能一条规则”的限制。

关闭或已到期规则只读；过期样例status0，不能恢复旧规则。普通SPU报价单基准可演示取价，只增改对象而不能移除原对象；含分类继承或行情基准的规则本期只读。整单折扣作用于适用商品，不自动折扣运费等费用。例如商品100元＋运费10元，商品九折后为100元。

## 5. 一次性报价单定时调价与失败处理

列表显示任务名称、报价单、计划执行时间、商品数、调价方式、原生状态和操作，不显示执行结果列。异常徽标与状态并存，已生效不代表每项成功。

新建填写名称、人民币报价单、未来整点和至少1项商品。保存后锁报价单，换单需另建；未开始可改名称、时间、商品和目标价，已生效／已结束只读。未来整点代表计划时刻，不保证秒级完成。

预约调价复用客户协议调价的“先选品—批量设置价格—例外单独设置”，列表只显示标准价、目标价摘要和操作。直接指定标准价只填新价格；按现标准价调整一次才选择百分比、加减金额或倍数。填入后保留确定目标价，不在执行时重算。覆盖已有不同设置需确认，取消不改草稿，新选商品待设置；无法按标准价计算的商品单独设价后才能保存。多个任务命中相同SKU时按计划先后提示，实际后写入结果仍由执行与异常情况决定。共享任务要求核对完整关联客户。

导入支持XLSX首表、UTF-8／GB18030 CSV、TSV：商品编码或SKU、调整方式／数值或目标价、销售单位。文件内重复、跨单、单位、格式或金额校验错误整批拒绝，草稿不变；与草稿重复SKU确认后更新。导入只改价格，不覆盖其他商品资料。5MB、5000行、XLSX解压20MB；公式和百分比格式需转为明确数值。

失败详情有独立25条分页，复制操作使用全量明确失败项，不只当前页；成功项保留、不自动撤回。失败项复制为独立新草稿，重新确定整点时间与价格，核对再保存；无失败明细时去原系统核查。原型不自动执行、自动补执行、重试或恢复价格。

未保存修改关闭前确认；取消放弃应留在原草稿，保存成功不再弹出放弃修改确认。

## 6. 操作记录、提示与演示保存

操作记录只对定价主管显示，支持对象／操作人／摘要搜索，每页25条；详情展示原值与新值并分页。记录包含人工调整、原规则编辑、任务新建／修改和失败项重建；本地日志不是原生接口字段，也不提供自动回滚。

辅助解释采用问号Tooltip，支持鼠标、键盘、触屏；Esc先关提示。实际字段、状态和必须处理的异常直接展示。桌面保持列表布局，窄屏表格内部横向滚动。

存储键 `guanmai-pricing-prototype-v2`，version2、schema4；旧键保留但不迁移。客户任务为同版新增集合；已存数据没有该集合时补空，原规则保留，不推断历史任务。新初始演示提供明确任务样例。重置只清除本版演示数据、对话和日志。全部原型结果仅用于验证产品设计，不代表权限、并发、队列与真实价格接入完成。
