# 定价助手原型试用记录

本轮通过浏览器中的按钮、输入框、客户下拉和弹窗，模拟正常使用者实际操作。主策略流程模拟在报价适用期内的 2026 年 10 月 2 日使用，另测试了报价期外、策略到期和延迟确认的情况。

## 需求整理

- 依据面向整张订单，首页不再选择商品；进入具体依据卡片后，查看商品明细、来源并调整该商品。
- 客户使用单选下拉，每项展示客户名、商品数、依据类型标签。
- 企业微信、指定外部来源、协议及业务条件提供可阅读的示例记录。
- 不同客户可通过各自对话制定不同策略；统一策略页查看当前、待生效及历史安排。
- 同一客户、同一时段至多一套生效策略，不同客户互不影响。时间按北京时间计算，开始包含、结束不包含。
- 策略保存、报价确认、策略启用、原系统落实与录单核验分别处理。

## 已走通的场景

| 使用过程 | 结果 |
| --- | --- |
| 下拉选客户，查看五类整单依据 | 商品数量与明细随客户切换，去掉了页面级商品选择器 |
| 点依据卡片，查看商品来源，再调整该商品 | 规则预选仅包含该商品，先预览再应用；协议冲突商品保持不变 |
| 打开企微、外部来源、协议及业务条件 | 可阅读内容、日期、适用对象、核实状态和约束 |
| 对话调整报价、保存策略名称、确认整版价格 | 草稿不能直接启用；确认后策略保留独立价格与依据快照 |
| 两个客户制定不同价格并在相同时段启用 | 两个客户互不覆盖；同客户重叠会先显示冲突 |
| 取消替换，随后明确确认替换 | 取消不改变原安排；确认后旧策略衔接结束或取消未来计划，不自动恢复 |
| 调整结束时间、停用、复制历史、重新安排 | 已发生的开始时间不允许改写；时间和启停变化可追溯 |
| 修订报价、刷新页面、人工落实与差异核验 | 原快照保留，本地记录恢复正常，录单差异阻止核验通过 |
| 桌面及 390 / 320 像素窄屏 | 页面无横向溢出，客户选择、详情与主要操作可用 |

## 试用发现并修复

1. **未来策略取消后的时间倒置**：改为显示原计划和取消时间，状态为“已取消”。
2. **旧报价被直接用于新时段**：超出来源报价周期时，展示整版价格并要求重新核实，另存新时段确认；原报价版本不变。
3. **协议期限被忽略**：含固定协议的正式策略超出已知协议期间时阻止启用，提示先核实新约定。
4. **停用弹窗打开期间策略到期**：确认时重新判断，保留原结束时间。
5. **“从现在开始”的时间与复核区未同步**：立即展示所需复核；用户延迟确认时按实际确认时间衔接策略，避免回填过去时间。

本轮未发现仍会阻断上述正常试用流程的问题。自然语言仍是限定规则解析；来源、客户和策略为演示数据，仅在当前浏览器保存，尚未连接真实 AI、企微、ERP 或多人后台。
