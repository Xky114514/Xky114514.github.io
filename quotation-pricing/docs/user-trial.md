## 正常使用流程

1. 选择晨禾食堂。因为关联多张报价单，先明确选“日常配送报价单”。默认范围为“客户专属价”。
2. 查看采购参考、报价记录或市场行情；客户资料可在尚未选报价单时直接查看。
3. 输入“Q1-0001按报价单基础价上调3%”，或打开“按条件调整”，通过名称、编码、规格、分类选择商品。
4. 填写有效日期，核对计算方式、基准和每日时段；生成预览。缺少有效期不能继续。
5. 查看报价单基础价、客户当前适用价、拟调整值及影响范围。应用演示只更新本地规则。
6. 如要改共享价格，切换“报价单基础价”，再次选择商品并预览各关联客户的影响。
7. 在“规则与调价”查看所有客户的现有规则及周期任务；只可修改未开始任务的名称和执行时间。

## 验收场景与证据

| 场景 | 结果 |
|---|---|
| 一客多单、一单多客 | 晨禾关联两张报价单；日常报价单关联三家客户；多单时不默认猜选 |
| 客户专属调整 | 大白菜从当前基础 5.00 计算 10% 浮动规则后，晨禾为 5.50；共享基础及桥头仍为 5.00 |
| 共享基础调整 | 鲜鸡蛋基础从 7.60 改为 8.00 后，晨禾固定价仍 7.40、云栖倍率价为 7.60、桥头为 8.00 |
| 同名跨单 | Q1 与 Q2 的同名商品使用不同 SKU，修改 Q1 不改变 Q2；选择状态也不串单 |
| 上下文变化 | 切客户、报价单或范围后清空选择；切回旧范围也不能应用旧预览 |
| 刷新与存储 | 本地业务数据和对话保留；旧预览不能复活，新预览 ID 不碰撞；旧版存储哨兵完整保留且不迁移 |
| 规则互斥 | 共用多人规则展示完整影响客户并阻止单客户覆盖；日期重叠、分类及有效 SPU／整单规则有明确阻止信息 |
| 多规则共存 | 不同 SKU 或不重叠日期可以建规则，没有“一客只能一套策略”的限制 |
| 当前价一次计算 | 按客户当前适用价计算的调整保存为固定值，不伪装成浮动比例 |
| 阶梯价格 | 无数量时不显示确定适用价；输入 30 后显示对应数量档。客户协议调整不覆盖阶梯表 |
| 时价和缺失 | 时价待定显示“待定价”；不可将占位 0 用于调幅。缺失采购／行情为“—”或空态，不自行补值 |
| 单位与金额 | 箱销售价与公斤基本价分别显示；采购参考不再换算；行情、订单元值不除以 100；固定金额跨单位须分批 |
| 自然语言边界 | 两个基准、错误的“元/斤”、未知价格参与低价筛选、基础价筛选错用协议价等都已保护 |
| 300 商品 | 每页 25／50／100 条；名称、编码、规格搜索；分类与跨页选择、筛选后保留已选项正常 |
| 1000 商品 | 选择全部匹配得到 1000 个 SKU；搜索末条仍已选；预览只展示一页但实际应用全部 1000 条 |
| 报价记录 | 展示稀疏变更及适用日期，不补造逐日价格、不当作客户成交价；日期范围倒置有提示 |
| 客户资料 | 账号结算方式与原生配置正确；统计结果独立于报价单和最近订单筛选，不混加商品数量 |
| 客户切换 | 原运营时间不适用新客户时，选择框和最近订单列表一致回到可用运营时间 |
| 周期任务 | 未开始任务可改名改时间；唯一性及时间校验有效；保存不改变状态，浏览器时间不宣告执行成功 |
| 关闭规则 | 关闭、无效规则仅查看；不提供会误导为“修改”却新建规则的入口 |
| 窄屏 | 390／320 宽度页面无横向外溢；商品表和资料表内部横向滚动；弹窗可关闭、表单可滚动 |

## 试用中修正的问题

- 搜索资料时重绘触发 change 事件造成重复渲染：查询由 input 统一处理，消除运行时异常。
- 刷新后的新旧预览 ID 冲突：采用每次会话唯一标识，历史预览保持只读说明。
- 缺失价被隐式转换为 0、基础价筛选使用客户价：按明确口径传入筛选，未知值排除。
- 箱商品接受“元/斤”表达：解析校验销售单位；外币商品不接受人民币金额的默默套用。
- 规则基本单位与销售单位混淆：预览标明计算单位，多商品换算不同不预填统一值。
- 小屏多列表格被挤成竖排：设置表格最小宽度与内部滚动，保留列表结构。
- 运营时间筛选跨客户残留：校验客户可用运营时间，并保持控件与数据同步。

## 保留的边界

本轮是演示原型。对话为有限语法解析，没有真实 AI 或自由推理能力；不识别的要求会提示改用结构化操作。客户购买分析只提供指定日期与时间口径的演示快照，更换到无数据的查询范围不会伪造结果。

SPU 上浮率、整单折扣等原生规则可查看并参加必要冲突检查，本轮不模拟其精确结算；需原系统确认。未来规则设置值不代表未来实际结算价格。多人规则不自动拆分；关闭／无效规则不在本原型重新启用。

尚未验证真实接口权限、并发更新、接口可用性、服务端性能或任务执行。没有真实数据接入、后端修改、Excel 新任务导入或 GitHub 发布。上述离线通过不能代替后续联调。
