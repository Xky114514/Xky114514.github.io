# 订单查看范围需求说明

## 需求范围

在「销售录单 → 设置 → 功能设置」中提供“订单查看范围”配置，用于控制操作员在订单审核列表中可查看的数据范围。

## 功能规则

- 提供“本人及未分配订单”和“全部订单”两个互斥选项。
- 默认选择并生效“全部订单”，操作员可查看当前租户内的全部订单。
- 选择“本人及未分配订单”时，仅展示审核员为当前操作员或尚未分配审核员的订单。
- 切换选项后需点击“保存”才生效；未修改时保存按钮置灰。
- 保存成功后更新“当前生效”标识；保存失败时保留原生效范围。
- 功能设置页不再展示“图框联动识别”和“倾斜图片自动校正”配置区域。

## 权限规则

- “订单查看范围”为租户级数据权限配置，仅租户管理员可查看和修改。
- 普通操作员不展示该配置入口，也不可通过接口自行修改配置。
- 普通操作员的订单审核列表按照租户当前生效的查看范围展示。
- 租户管理员不受“本人及未分配订单”限制，始终可以查看当前租户的全部订单。
- 如需由主管、组长等非管理员角色维护，应单独授予“管理订单查看范围”权限，不向全部普通操作员开放。

## 安全与审计

- 前端隐藏入口的同时，服务端必须校验修改权限，防止越权调用。
- 每次配置变更需记录租户、操作人、变更前范围、变更后范围和操作时间。
- 配置变更只影响后续查询结果，不修改订单的审核员分配关系和历史操作记录。
- 多人同时修改时应进行版本校验；保存失败或发生冲突时，继续使用原生效范围。
