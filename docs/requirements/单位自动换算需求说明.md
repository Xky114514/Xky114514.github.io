# 单位自动换算需求说明

## 1. 需求背景

客户下单时使用的计量单位不统一（如按"斤"下单、系统按"公斤"录单），需要人工换算数量，易出错且效率低。

新增"单位自动换算"能力：管理员预先配置"原始单位 → 目标单位"的换算关系及适用范围（群聊、客户），系统录单时自动完成单位换算与补齐。

## 2. 功能入口

销售录单 → 设置 → 功能设置 → 单位自动换算。

## 3. 界面与交互

### 3.1 总开关

- 卡片头部提供"单位自动换算"总开关，默认开启。
- 关闭后配置区域置灰不可操作，已保存配置保留但不生效；保存时提示"单位自动换算已关闭"。

### 3.2 单位配置列表

每条配置包含以下要素，一行展示：

| 要素 | 说明 |
|---|---|
| 原始单位 | 下拉选择，仅重量单位：斤 / 公斤 / 千克 / g / 吨。 |
| 目标单位 | 下拉选择，选项同原始单位；换算按固定物理倍率执行（如 1 公斤 = 2 斤 = 1000 g）。 |
| 适用群聊 | 点击打开范围选择弹窗，可多选。 |
| 适用客户 | 点击打开范围选择弹窗，可多选。 |
| 删除 | 移除该条配置。 |

- 提供"+ 新建单位配置"按钮，追加一条空白配置。
- 配置修改后需点击"保存"生效；保存成功提示保存条数，无配置时提示先新建。

### 3.3 范围选择弹窗

点击"适用群聊 / 适用客户"输入框后打开弹窗，能力如下：

| 能力 | 说明 |
|---|---|
| 搜索 | 按名称关键字实时过滤列表。 |
| 勾选 | 逐个勾选 / 取消勾选。 |
| 全选 | 一键勾选当前搜索结果内的全部对象，支持批量勾选与批量取消。 |
| 清空 | 取消全部已勾选。 |
| 计数 | 实时展示"已选 n / 总数"。 |
| 确定 / 取消 | 确定保存本次选择并回显；取消放弃修改。 |

### 3.4 范围回显规则

- 输入框内最多展示 6 个对象标签，超出部分以"+n"折叠展示（如选 8 个客户，展示 6 个 + "+2"）。
- 全部勾选时，不逐个展示，直接显示"全选"标签。
- 未选择时显示"点击选择"占位提示。

## 4. 业务规则

- 仅重量类商品参与自动换算；非重量类商品不补齐、不换算单位。
- 同一配置内原始单位与目标单位可为不同重量单位的任意组合，换算按固定物理倍率执行。
- 执行优先级：客户自身下单记忆 > 本配置 > 群聊共享记忆。
- 同时命中群聊范围和客户范围时，按客户维度的命中结果执行。
- 单位配置合计最多 50 条；达到上限后"新建单位配置"不可用并提示。
- 范围调整与配置删除仅影响后续录单，已生成的订单不回溯变更。
- 不做商品维度配置，仅从群聊、客户两个维度圈定适用范围。

## 5. 权限规则

- 该配置为租户级配置，仅租户管理员可查看和修改。
- 普通操作员不展示配置入口；服务端需校验修改权限，防止越权调用。

## 6. 安全与审计

- 每次配置变更记录租户、操作人、变更内容（新建 / 修改 / 删除 / 开关状态）和操作时间。
- 多人同时修改时进行版本校验，冲突时保存失败并保留原生效配置。

## 7. 验收标准

1. 功能设置中出现"单位自动换算"卡片，总开关可切换，关闭后配置区域置灰。
2. 可新建配置，选择原始单位与目标单位（均为重量单位下拉）。
3. 点击群聊/客户输入框打开选择弹窗，支持搜索、逐个勾选、全选（作用于搜索结果）、清空，计数实时更新。
4. 选择超过 6 个对象时，输入框展示 6 个标签 + "+n"；全部勾选时展示"全选"。
5. 可删除配置、保存配置，保存成功有明确提示。
6. 关闭总开关后保存，配置不生效；重新开启后无需重新配置即可恢复生效。
