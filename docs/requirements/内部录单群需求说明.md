# 内部录单群需求说明

## 1. 需求背景

部分客户不方便邀请机器人进入其外部群聊，但业务人员仍需要在一次录入中提交多个客户的销售订单。

新增“内部录单群”作为后台录单容器。管理员可在后台创建内部录单群、绑定多个客户，再由操作人员在“订单录入”中选择该内部群，统一录入并拆分多个客户的订单。内部录单群不对应真实微信、企业微信或邮件群，也不向客户发送消息。

## 2. 目标

- 支持一次录入多个客户的销售订单，无需机器人进入客户群。
- 复用现有群聊管理、订单识别和审核流程，尽量不改变原页面结构。
- 在管理端和订单录入端清晰区分内部录单群与外部群聊。

## 3. 功能入口

入口：销售订单录单 → 客户管理 → 群聊管理。

群聊管理页面原“新增邮件群”调整为“新增群”下拉按钮，包含：

- 邮件群
- 内部录单群

选择“内部录单群”后进入内部录单群创建流程。

## 4. 创建内部录单群

| 字段 | 规则 |
|---|---|
| 群聊名称 | 必填；用于群聊管理、订单录入和订单审核中的来源识别。 |
| 绑定客户分组 | 必填；用于初始化该内部群可录单的客户范围。 |
| 审核员 | 选填；设置该内部群产生订单后的默认审核员。 |
| 下单时段 | 选填；沿用现有群聊的下单时段规则。 |

创建成功后，群聊类型固定为“内部录单”。

## 5. 群聊管理列表

内部录单群与其他群聊共用同一张列表，字段位置保持一致，差异如下：

| 字段 | 内部录单群展示规则 |
|---|---|
| 群聊名称 | 展示内部录单群名称。 |
| 类型 | 展示“内部录单”标签。 |
| 成员数 | 保留现有列表字段及统计口径；详情中不提供群成员维护。 |
| 客户 | 展示当前已绑定客户数量。 |
| 审核员 | 展示并允许维护默认审核员。 |
| 发言 | 不展示内容及开关。 |
| 订单价格 | 沿用现有字段。 |
| 下单时段 | 沿用现有字段。 |
| 催单 | 不展示状态和设置入口，且不能被批量催单选中。 |
| 操作 | 保留“详情”“删除”等现有操作。 |

## 6. 内部录单群详情

### 6.1 基本信息

详情顶部保留群聊名称、类型、状态、绑定客户数、下单时段、订单审核员和回单处理人。

内部录单群没有真实机器人会话，因此不展示“机器人发言”配置。

### 6.2 标签页

内部录单群详情仅保留：

- 客户列表
- 拆单设置

不展示：

- 群成员
- 催单设置

### 6.3 客户管理

客户列表右上角提供“客户管理”按钮，不再跳转客户分组页面。点击后打开双栏客户管理界面：

| 区域 | 功能 |
|---|---|
| 可选客户 | 展示当前租户内可绑定客户，支持按客户名称、ID或编码搜索。 |
| 已选择 | 展示当前内部录单群已绑定的客户。 |
| 添加 | 将可选客户加入当前内部录单群。 |
| 移除 | 将客户从当前内部录单群移除。 |
| 一键添加全部 | 将当前可选客户全部加入已选择列表。 |
| 确认 | 保存本次客户范围调整。 |
| 取消 | 放弃本次尚未确认的调整。 |

客户分组只作为创建时快速初始化客户范围的方式；创建后可通过“客户管理”继续增减具体客户。

## 7. 订单录入

订单录入左侧继续使用“客户 / 群聊”两个入口：

1. 切换至“群聊”后，内部录单群与其他群聊一起展示。
2. 内部录单群名称前展示“内部”标签，用于与微信、企业微信、邮件群区分。
3. 选择内部录单群后，可录入文字、图片、Excel、Word或PDF订单内容。
4. 一次录入可包含该内部群已绑定的多个客户，识别结果按客户分别生成订单。
5. 订单产生后的审核员、下单时段和拆单规则，按当前内部录单群配置执行。

## 8. 业务规则与限制

- 内部录单群是后台业务容器，不创建或关联真实外部群聊。
- 内部录单群不支持机器人发言、群成员同步和催单。
- 内部录单群只能用于其已绑定客户的订单录入。
- 识别到未绑定客户时，不得自动归入其他客户；应保留待确认状态，由操作人员选择或先完成客户绑定。
- 一次内容识别出多个客户时，应分别生成客户订单，不得合并为一个客户订单。
- 调整绑定客户只影响后续录入；已经创建的订单及其来源记录不随客户解绑而改变。
- “内部”标签仅用于来源区分，不改变订单状态、审核流程或计费规则。

## 9. 与外部群聊的差异

| 能力 | 内部录单群 | 微信/企业微信群 |
|---|---|---|
| 真实群聊会话 | 无 | 有 |
| 后台录入多客户订单 | 支持 | 支持 |
| 机器人发言 | 不支持 | 支持 |
| 群成员管理 | 不支持 | 支持 |
| 催单 | 不支持 | 支持 |
| 客户管理 | 支持 | 支持 |
| 拆单设置 | 支持 | 支持 |

## 10. 验收标准

1. “新增群”下拉中可分别创建邮件群和内部录单群。
2. 内部录单群在列表中显示“内部录单”类型，发言列和催单列为空。
3. 批量设置催单时，内部录单群不能被选中。
4. 内部录单群详情不出现“机器人发言”“群成员”“催单设置”。
5. 点击“客户管理”可打开双栏界面，并完成客户搜索、添加、移除和确认。
6. 订单录入切换至“群聊”后，内部录单群显示“内部”标签。
7. 选择内部录单群后可录入多个已绑定客户的订单，并按客户分别生成订单。
8. 未绑定客户不会被系统自动错误归属。
