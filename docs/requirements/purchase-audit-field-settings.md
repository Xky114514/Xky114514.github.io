# 采购审核明细字段设置

## 需求范围

适用于「采购单审核 → 采购单详情」和「采购入库单审核 → 采购入库单详情」的商品明细及字段设置。

## 字段设置规则

- 详情页提供“字段设置”按钮，采购单与采购入库单分别配置、互不影响。
- 字段分为必选字段、可选字段和自定义字段。
- 必选字段默认展示且不可取消；可选字段和自定义字段可勾选或移除。
- 右侧“已显示字段”中的全部字段均支持拖拽排序，必选字段也可调整位置。
- 保存后，所选字段及排列顺序同步应用到当前单据类型的商品明细表格。
- 支持按字段名称搜索，并提供刷新字段、恢复默认操作。

## 采购单字段

| 分类 | 字段 |
|---|---|
| 必选字段 | 识别文本、商品名称、数量 / 单位、单价 |
| 可选字段 | 总价、备注、商品自定义编码、采购单（采购单位） |
| 自定义字段 | 采购用途、到货要求、供应商货号 |

默认展示必选字段，以及“总价、备注”；其他字段默认不展示。

## 采购入库单字段

| 分类 | 字段 |
|---|---|
| 必选字段 | 识别文本、商品名称、入库数量（采购单位）、入库数量（基本单位）、采购数量、差异 |
| 可选字段 | 单价、总价、备注、商品自定义编码、损耗数（基本单位） |
| 自定义字段 | 到货批次、到货温层、质检要求 |

默认展示必选字段，以及“单价、总价、备注”；其他字段默认不展示。

## 入库数量换算

- 换算公式：**入库数量（采购单位） × 采购规格 = 入库数量（基本单位）**。
- “采购规格”在计算时表示每个采购单位对应的基本单位换算系数。
- 示例：采购规格为 `10 千克/袋`，入库数量（采购单位）为 `8 袋`，则入库数量（基本单位）为 `80 千克`。
- 入库数量（采购单位）或采购规格发生变化时，系统同步重新计算入库数量（基本单位）。
- 未配置有效采购规格时，不自动换算，并提示操作员补充或确认采购规格。

## 验收标准

1. 两类详情页的字段设置内容符合上述分类，不出现跨单据类型字段。
2. 必选字段不可取消，可选字段和自定义字段可以勾选、取消或从右侧移除。
3. 右侧全部已显示字段均可拖拽，保存后明细表格列顺序与右侧顺序一致。
4. 采购入库单能按采购规格正确换算并展示基本单位数量。
