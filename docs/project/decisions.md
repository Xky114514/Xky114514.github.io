# 已确认决策

## D-001 项目记录目录

- 决策：使用默认目录 `docs/project/` 保存项目管理记录。
- 来源：用户指令（2026-08-14）。

## D-002 流程与门禁

- 决策：流程依次为“需求分析 → 产品确认 → 前端设计与实现 → 产品验收 → 完成”。
- 决策：无产品确认不得进入前端实现；无验证证据不得标记前端完成；无产品验收不得关闭任务。
- 来源：用户指令（2026-08-14）。

## D-003 状态集合

- 决策：仅使用“待分析、分析中、待产品确认、设计实现中、待验收、验收未通过、已阻塞、已完成”。
- 来源：用户指令（2026-08-14）。

## D-004 交接完整性

- 决策：每次交接必须包含范围、产物、证据、遗留问题、负责人和下一步。
- 来源：用户指令（2026-08-14）。
