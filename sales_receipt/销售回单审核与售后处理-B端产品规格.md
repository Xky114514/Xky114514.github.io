# 销售回单产品说明

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 需求名称 | 销售回单审核与售后处理 |
| 版本 | V2.7 |
| 更新日期 | 2026-08-26 |
| 适用对象 | 回单审核员、售后处理人员、业务管理员 |
| 适用范围 | 销售回单查询、订单关联、商品核对、售后登记、非商品异常及后续售后 |

## 2. 产品定位

销售回单用于核对商户实际签收结果，并在同一审核页面完成商品售后和任务级非商品异常登记。页面保持销售回单审核主流程，不新建独立“售后单”审核界面。

核心原则：

- 以销售订单为核对基础，原始回单材料只读保留。
- 回单同时保留下单数和出库数；下单数用于追溯原始订单，出库数作为回单差异及商品售后运算基准。
- 正常签收与售后处理共用一个审核页面，售后处理按需登记。
- 同一商品可登记多个售后类型，也可在回单完成后继续追加后续售后。
- 非商品异常属于整张回单任务，不挂在某个商品条目下；同一任务可登记多项。
- 商品较多时提供搜索、筛选、异常定位和批量处理能力。

## 3. 角色、权限与前置条件

| 条件 | 规则 |
| --- | --- |
| 操作权限 | 操作人需具备回单审核或售后处理权限；涉及销售订单数量修改时，还需具备相应数量修改权限，部分状态可要求授权码。 |
| 订单锁定 | 销售订单被锁定后，不允许通过回单修改订单数量。 |
| 先款后货 | 未支付的先款后货订单，不允许修改出库数。 |
| 已发生售后 | 商品已有生效的退货或异常记录后，不允许再修改该商品的出库数；退货可按剩余可退数量追加，商品异常按对应类型规则继续登记。 |
| 销售实收结算 | 只有站点开启“按销售实收结算”后，回单实收数才可写入销售订单实收数。 |

## 4. 业务术语与数量口径

| 字段 | 含义 | 规则与限制 |
| --- | --- | --- |
| 下单数 | 商户下单时的原始数量 | 页面换算为基本单位后只读展示，仅用于追溯和对照，不参与回单差异及售后数量计算。 |
| 出库数 | 实际从仓库发出的数量 | 页面以基本单位只读展示，是销售回单差异计算和商品售后处理的数量基准。出库数可小于、等于或大于下单数。 |
| 实收数（页面显示为“签收数”） | 商户实际收到的数量 | 页面按基本单位录入。空值表示尚未确认；`0` 表示明确未收到。 |
| 差异数 | 实际出库数量与商户实收数量之差 | 按基本单位计算“出库数－实收数”。 |
| 异常数 | 商品发生质量、破损等异常的数量 | 必须大于 0、不得超过当前有效出库数，并符合商品数量精度。 |
| 应退数 | 本次登记退货的数量 | 必须大于 0，且本次应退数与历史累计退货数之和不能超过当前有效出库数。 |
| 可退数量 | 当前商品仍允许登记退货的数量 | 以当前有效出库数扣减全部有效累计退货数后的余额为准。退货总数不得大于实际商品出库数。 |

销售订单列表中的下单数和出库数可能不同，销售回单不得再以两者默认相等为前提。回单页面的下单数、出库数、实收数和差异数均以商品基本单位展示或计算；其他入口使用销售单位时，应先按单位换算比例转为基本单位再比较。数量保留位数遵循商品数量精度。

## 5. 回单状态

| 状态 | 说明 | 可执行操作 |
| --- | --- | --- |
| 识别中 | 系统正在识别回单材料 | 查看识别进度；不进入审核员的回单审核列表，也不作为列表筛选状态。 |
| 待处理 | 已生成审核任务，尚未完成审核 | 核对订单与商品、保存、登记售后、登记非商品异常、提交、作废。 |
| 已完成 | 回单审核结果已提交 | 查看历史结果；不修改已提交记录，可继续追加后续售后。 |
| 已作废 | 当前回单任务不再生效 | 只读查看，不允许继续审核或登记售后。 |

## 6. 回单任务列表

![销售回单任务列表](./docs/images/receipt-list.png)

列表支持按状态、商户、时间范围和操作员查询。列表展示回单时间、来源、商户、操作员、处理概况及可执行操作；待处理任务可查看或作废，已完成任务可查看，已作废任务只读展示。

## 7. 原始材料与销售订单关联

原始回单材料在左侧只读展示，审核结果在右侧处理。系统可自动关联销售订单，审核员也可查询并更换订单。

![销售订单查询与更换](./docs/images/receipt-order-query.png)

更换订单时遵循以下规则：

- 只允许选择与当前商户匹配、可用于回单核对的销售订单。
- 已提交的回单不可更换原销售订单。
- 更换成功后，按新订单重新生成商品核对明细，并清空尚未提交的商品售后；任务级非商品异常继续保留，但提交前必须重新确认。
- 取消更换或更换失败时，保留原关联订单及当前编辑内容。
- 页面必须明确展示当前关联订单，未关联订单时不得提交回单。

## 8. 商品核对

![销售回单商品核对](./docs/images/receipt-review-products.png)

字段口径以本节为准：商品核对表展示八列，依次为序号、订单商品、识别商品、下单数、出库数、实收数、差异数、备注。数量及单位在对应数量单元格内展示。

| 字段 | 操作要求 |
| --- | --- |
| 序号 | 表示商品在当前核对列表中的顺序。 |
| 订单商品 | 展示关联销售订单中的商品，只读。 |
| 识别商品 | 展示回单材料中的识别结果；未识别、重复识别或订单无此商品时仅供核对，不回写销售订单商品。 |
| 下单数 | 销售订单下单数量换算为基本单位后只读展示，仅供对照。 |
| 出库数 | 销售订单当前有效出库数量，按基本单位只读展示。 |
| 实收数 | 页面字段显示为“签收数”，按基本单位录入；空值与 `0` 必须区分。 |
| 差异数 | 按基本单位自动计算“出库数－实收数”。实收数为空时，不生成确定差异。 |
| 备注 | 记录当前商品的核对或实收补充信息。 |

大量商品场景可按待核对、有差异、未识别、已修改、已售后等状态筛选；这些状态用于辅助处理，不作为商品核对表的固定列。

## 9. 销售订单数量更新规则

回单页直接录入的是实收数，页面字段显示为“签收数”。是否能写入销售订单实收数，以及是否进一步同步出库数，由销售订单状态、权限和站点配置共同决定。

| 销售订单状态 | 写入实收数 | 因配置同步修改出库数 | 说明 |
| --- | --- | --- | --- |
| 等待分拣 | 不允许 | 不允许 | 尚未进入实际分拣与交付环节；可保存回单草稿，不写入订单数量结果。 |
| 分拣中 | 允许 | 允许 | 可按实际分拣、称重和签收结果调整，但需满足权限与配置。 |
| 配送中 | 允许 | 允许 | 可处理配送过程中的数量差异，但需满足权限与配置。 |
| 已签收 | 允许 | 允许 | 可补录或修正最终实收结果，但需满足权限与配置。 |

数量联动口径：

1. 未开启“按销售实收结算”时，回单实收数仅保存在回单审核结果中，不写入销售订单实收数。
2. 开启“按销售实收结算”后，可按上表及权限写入销售订单实收数，并重新计算实收差异、实收金额和相关结算金额。
3. 销售回单差异和销售订单实收差异统一按“出库数－实收数”计算；下单数不参与差异运算。
4. 只修改实收数时，默认不修改销售订单出库数。
5. 只有同时开启“实收数同步更新出库数”，且当前商户在同步范围内，销售订单出库数才随实收数变化。
6. 录入或确认实收数不会修改销售订单下单数和既有退货数。

## 10. 对销售出库单和配送单的影响

### 10.1 销售出库单

- 只写入实收数、未同步出库数时，销售出库单数量不变。
- 销售订单出库数发生变化，且销售出库单仍为“未出库”时，销售出库单一般同步更新。
- 销售出库单已经出库时，默认不覆盖。只有操作人具备“修改销售订单时同步已出库销售出库单”权限，才可冲销原出库并按新数量重新出库。
- 重新出库时库存不足，销售出库单可能停留在“未出库”，需人工处理。

### 10.2 配送单

- 配送单跟随出库数，不直接跟随实收数。
- 配送单未被人工修改且出库数未锁定时，可随销售订单出库数同步。
- 配送单已人工修改并锁定出库数时，不再被销售订单覆盖。
- 只修改实收数、没有同步修改出库数时，配送单数量不变。

## 11. 商品售后处理

审核员从销售订单商品中选择需要处理的商品，不以“出库数与实收数是否存在差异”作为能否登记售后的前置条件；但商品售后只能针对当前有效出库数大于 `0` 的订单商品，所有售后数量判断均以实际出库商品和当前有效出库数为基础。

![新增售后商品](./docs/images/receipt-after-sales-product-picker.png)

![商品售后处理](./docs/images/receipt-review-after-sales.png)

每个售后商品可添加多条售后类型：

| 售后类型 | 主要字段 | 规则 |
| --- | --- | --- |
| 商品异常—异常 | 售后原因、异常数 | 单条异常数必须大于 0 且不得超过当前有效出库数；同一商品可登记多条不同原因。 |
| 商品异常—退货 | 售后原因、应退数 | 应退数必须大于 0；历史累计退货数与本次应退数之和不得超过当前有效出库数。 |

售后处理规则：

- 同一商品可同时登记异常和退货，也可登记多条同类售后。
- 同一商品可分多次售后处理；已提交记录只读，后续新增内容形成新的处理记录。
- 删除商品仅移除当前尚未提交的售后编辑内容，不影响已提交历史。
- 商品已提交售后后，出库数不可再修改；退货可按剩余可退数量追加，商品异常按对应类型规则继续登记。
- 不同商品异常原因可能指向同一批实物，因此异常数按单条校验，不在多条异常记录之间累计扣减；退货数量仍单独执行累计上限。
- 商品售后区域保留商品搜索、新增售后商品及展开/收起能力，不展示商品总数、未处理数，也不设置“全部／待完善／已完善”筛选。

累计退货范围为当前销售订单商品关联的全部有效、已提交退货记录，包括当前回单历史轮次及其他有效售后入口产生的记录。作废或尚未生效的记录不占用退货额度。所有数量换算为基本单位后累计，总退货数不得超过当前有效出库数。每次提交前，系统按最新出库数和最新有效退货历史重新计算剩余可退数量；历史累计退货数已达到或超过出库数时，不允许新增退货。同次提交会修改出库数时，以本次更新完成后的有效出库数作为退货上限，并在生成退货记录前再次校验。

## 12. 非商品异常

非商品异常属于整张回单任务，与商品条目分开管理；一张回单可登记多项。

| 字段 | 含义与限制 |
| --- | --- |
| 异常原因 | 必填，描述配送、服务、单据等非商品问题。 |
| 责任部门 | 必填，选择承担问题处理责任的部门。 |
| 跟进部门 | 必填，选择负责后续跟进的部门。 |
| 处理方式 | 必填，按当前业务选项处理。 |
| 金额方向 | 涉及金额时选择增加或扣减。 |
| 金额 | 处理方式为退款或补差价时必填，且必须大于 0。 |
| 处理状态 | 必填，记录当前处理进度。 |
| 描述 | 必填，补充问题经过或处理备注。 |

非商品异常不占用商品可退数量，也不改变某个商品的实收数、异常数或应退数。

非商品异常区域不展示异常总数，仅保留异常明细和“新增异常”操作。

## 13. 大量商品场景

当销售订单商品达到 30 条及以上时，页面提供搜索、核对状态筛选、上一条/下一条问题商品及批量操作，减少逐行滚动。批量操作包括选择当前结果、加入售后、批量备注、标记已核对和撤销。

![大量商品审核](./docs/images/receipt-review-large-order.png)

批量操作只作用于当前明确选中的商品，不覆盖已登记售后、未识别、重复识别或仍有待核对问题的商品。提交前仍需完成全量校验。

## 14. 保存、提交与作废

### 保存

- 保存当前商品核对、未提交售后和非商品异常内容。
- 保存不代表审核完成，不触发最终订单数量联动。

### 提交回单

提交前必须满足：已关联销售订单；所有需核对商品已有明确结果；售后数量和必填字段合法；非商品异常内容完整。若没有商品售后和非商品异常，操作员必须在最终提交确认中明确确认本次无需售后。

同一次提交同时包含数量变化和商品售后时，按以下顺序处理：

1. 提交前先检查商品是否已有历史生效售后；已有历史退货或异常时，本次不得再修改该商品出库数。
2. 商品没有历史生效售后时，先计算本次实收数及按配置触发的出库数更新结果。
3. 以本次更新后的有效出库数重新校验异常数和累计退货数。
4. 全部校验通过后，先更新实收数及出库数，再生成本次商品售后记录；本次售后生效后，后续不得再修改该商品出库数。

任一商品售后数量校验不通过时，本次提交整体不成功：销售订单数量不更新，也不生成部分售后记录。

若商品已有历史生效售后，同时站点开启“实收数同步更新出库数”，本次仍可按规则写入实收数，但该商品跳过出库数同步，并明确提示“商品已有售后，出库数保持不变”。

提交后：

- 回单状态变为“已完成”，本次核对与售后记录转为只读历史。
- 按第 9、10 节规则决定是否更新销售订单、销售出库单和配送单。
- 系统不要求操作员在审核前预先选择“正常签收”模式。

### 作废

- 仅待处理回单允许作废。
- 作废前应二次确认；作废后不再参与审核和数量联动。

## 15. 已完成回单与后续售后

![已完成回单继续售后](./docs/images/receipt-completed-followup.png)

已完成回单仍允许进入“售后处理”追加后续售后：

- 历史商品核对、历史售后和历史非商品异常只读保留。
- 新增售后以独立批次提交，不覆盖原提交结果。
- 同一商品可以多次追加售后，但全部有效退货记录的累计数量始终不得超过当前有效出库数。
- 后续售后提交前仍需校验权限、商品状态和数量精度；退货校验剩余可退数量，商品异常按对应类型的数量规则校验。

## 16. 关键限制汇总

1. 回单必须关联有效销售订单后才能提交。
2. 实收数空值不等于 `0`；空值表示未确认，`0` 表示明确未收到。
3. 差异数统一按“出库数－实收数”计算，下单数仅供追溯和对照。
4. 出库数允许小于、等于或大于下单数，销售回单运算不得默认两者相等。
5. 总退货数不得超过当前有效出库数。累计范围包含该销售订单商品的全部有效已提交退货记录。
6. 销售订单、销售出库单和配送单的变化受状态、权限、锁定情况及站点配置共同控制。
7. 已提交售后不可修改或删除，只能追加新的处理记录。
8. 非商品异常按回单任务管理，可登记多项，不挂在商品行中。
