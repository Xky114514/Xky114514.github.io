# 商品报价单展示与按报价单拆单

- 版本：V1.1
- 状态：待评审
- 变更摘要：拆单依据由“报价单运营时间”修正为“报价单唯一 ID”
- 变更范围：销售录单商品明细、报价单详情、确认下单拆单逻辑

## 1. 背景与目标

AI 按商品名称识别商品，同名商品可能同时存在于多张报价单中，且不同报价单的运营时间可能相同或重叠。

本次目标：在商品明细中展示报价单来源，由操作员选择具体商品以确定报价单；确认下单时，按照报价单拆分子订单。

不包含：报价单新增、编辑、停用等管理能力；不调整现有门店、收货日期等拆单规则。

- 使用角色：销售录单操作员。
- 数据范围：当前操作员有权处理的销售订单及其商品、报价单。
- 页面入口：销售录单/订单审核页面的商品明细；点击报价单名称打开详情，关闭后返回当前明细位置。
- 已确认口径：报价单唯一 ID 是本需求的拆单依据；运营时间不参与分组、合并或拆分判断。
- 推荐默认：无报价单商品统一进入独立的“无报价单”子订单。

## 2. 报价单展示与选择

| 规则 | 说明 |
|---|---|
| AI 初始匹配 | AI 按商品名称查找商品。若同名商品存在于多张报价单，商品明细的“报价单”字段展示全部匹配结果。 |
| 展示方式 | “报价单”为只读字段。单张时展示报价单名称；多张时单行展示“首张报价单 +N”，`N` 为除首张外的剩余报价单数量，点击 `+N` 展开其余报价单；无匹配时展示“—”。 |
| 商品选择 | 商品名称下拉按具体商品展示候选项，每个候选项展示其所属报价单。操作员选择候选商品后，商品名称、规格、单价及报价单同步更新。 |
| 报价单详情 | 点击报价单名称打开详情。详情仅展示报价单名称，以及商品名称、规格、单价；当前商品行高亮并显示“当前商品”。不展示有效期、运营时间和高亮说明文案。 |
| 可编辑性 | 操作员不能直接修改报价单，只能通过重新选择商品改变关联报价单。 |
| 提交校验 | 商品仍匹配多张报价单时，阻止确认下单并提示“请先选择具体商品，确认报价单”。无报价单商品允许下单，按“无报价单”规则处理。 |

## 3. 按报价单拆单规则

| 编号 | 规则 |
|---|---|
| BR-01 | 在现有门店、收货日期等拆单结果内，再按商品关联的报价单唯一 ID 分组。 |
| BR-02 | 关联同一报价单 ID 的商品进入同一子订单；报价单名称仅用于展示，不作为分组键。 |
| BR-03 | 关联不同报价单 ID 的商品必须拆成不同子订单，即使报价单名称、运营时间或商品完全相同，也不得合并。 |
| BR-04 | 报价单运营时间不参与拆单；系统不计算运营时间交集，也不因运营时间相同或重叠而合并子订单。 |
| BR-05 | `[推荐默认]` 无报价单商品统一进入独立的“无报价单”子订单，不得并入任一报价单子订单。 |
| BR-06 | 子订单保留报价单 ID、报价单名称；子订单内每条商品保留其报价单来源。无报价单子订单的报价单 ID 和名称为空。 |
| BR-07 | 不允许操作员跨报价单手动合并子订单。若既有拆单维度不同，同一报价单也可产生多个子订单。 |

示例：报价单 A 的运营时间为 `06:00~17:00`，报价单 B 为 `08:00~20:00`。无论两段时间是否重叠，A、B 的商品都拆为两个子订单；若三条商品均关联报价单 A，则进入同一个报价单 A 子订单。

## 4. 异常与边界

- 报价单已失效、停用或商品已移出报价单：提交时重新校验，失败时保留当前录单内容并定位到对应商品。
- 商品仍关联多张报价单：阻止提交，不自动选择报价单。
- 拆单失败：不生成部分子订单，原订单保持待处理状态，提示“拆单失败，请重试”。
- 重复点击确认下单：同一原订单只生成一次拆单结果。

## 5. 验收标准

1. 同名商品命中三张报价单时，明细展示“首张报价单 +2”，且字段不可直接编辑。
2. 选择具体商品后，报价单、规格和单价同步更新；再次打开页面仍能正确回显。
3. 报价单详情不展示有效期、运营时间及“黄色高亮行为当前商品。”，当前商品仍保持高亮。
4. 同一报价单 ID 下的多条商品，在其他拆单维度相同时生成一个子订单。
5. 不同报价单 ID 的商品，即使运营时间完全相同或重叠，也生成不同子订单。
6. 两张报价单名称相同但 ID 不同时，生成不同子订单。
7. 存在未唯一确定报价单的商品时，系统阻止确认下单并定位到对应商品。
8. 多条无报价单商品进入一个独立的“无报价单”子订单。
9. 重复点击确认下单不会重复生成子订单。

## 6. 待确认项

- “无报价单”子订单是否允许与人工指定报价单。推荐本期不允许；如需关联报价单，应返回商品明细重新选择商品。
