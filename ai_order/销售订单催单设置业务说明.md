# 销售订单群聊管理—催单设置需求说明

## 1. 需求概述


- 背景：固定周期下单的客户未按时下单时，销售人员需要人工逐群检查并催单，容易遗漏。
- 功能定位：催单配置归属于群聊。每个群聊维护一份当前生效配置，由“群聊管理”列表统一查看和批量维护，也可在群聊详情中单独修改。
- 目标：按群聊设置日常下单日期、提醒时间和催单话术；到点后若当天没有有效销售订单，由机器人在群内提醒一次。
- 范围：群聊管理列表的催单状态与批量设置、群聊详情的催单设置页签、自动检查与提醒记录。

## 2. 功能归属、角色与入口

- 功能归属：催单设置是“群聊管理”的子功能，配置与群聊绑定。
- 页面约束：不在销售订单“设置”中增加催单页签。
- 角色：具备群聊管理权限的管理员。
- 一级入口：AI 销售订单应用 → 客户管理 → 群聊管理。
- 列表批量设置：群聊管理 → 批量设置催单 → 勾选群聊 → 设置催单。
- 列表单群设置：群聊管理 → 目标群聊的“催单”列 → 设置。
- 详情单群设置：群聊管理 → 目标群聊详情 → 催单设置页签。
- 数据范围：只展示当前租户内有权管理的群聊；每个群聊只保留一份当前生效的催单设置。
- 依赖：群聊信道在线、机器人可发言、订单可按来源群聊和创建时间查询。

| 页面区域 | 作用 | 展示与操作规则 |
|---|---|---|
| 群聊管理列表 | 查看全部群聊的催单状态 | “催单”列位于“下单时段”之后、“操作”之前，只显示已启用/已停用和“设置”，不展示日期、时间、话术。 |
| 列表批量选择态 | 选择需要统一配置的群聊 | 支持任意多选及全选当前搜索结果；未选择群聊时“设置催单”置灰。 |
| 批量设置弹窗 | 用同一配置覆盖多个群聊 | 保存后只更新已选群聊，未选群聊不受影响。 |
| 群聊详情—催单设置 | 维护当前群聊配置 | 回显当前配置；保存只影响当前群聊。 |

## 3. 页面字段

### 3.1 查询与列表

| 字段 | 类型 | 默认/来源 | 规则 |
|---|---|---|---|
| 搜索关键词 | 输入框 | 默认空 | 去除首尾空格后，只按群聊名称模糊匹配。 |
| 群聊勾选 | 复选框 | 默认隐藏且不勾选 | 点击“批量设置催单”后列表进入选择态并显示复选框；可逐项勾选任意多个群聊，也可通过表头“全选”选择当前搜索结果。搜索不清空已经勾选但暂时不可见的群聊。 |
| 群聊名称 | 只读文本 | 来自群聊管理 | 群聊改名后展示新名称，原催单设置继续保留。 |
| 催单状态 | 状态标签和操作入口 | 来自群聊催单设置 | 只展示“已启用”或“已停用”及“设置”入口；列表不展示日常下单日期、提醒时间和话术。 |

### 3.2 单群/批量配置

| 字段 | 类型 | 必填与默认值 | 校验及联动 |
|---|---|---|---|
| 设置范围 | 系统自动确定 | 必填 | 列表单行设置或详情保存只更新当前群聊；批量设置更新所有已勾选群聊。未勾选群聊时“设置催单”按钮置灰。 |
| 启用催单 | 开关 | 必填；批量设置默认开启 | 关闭后不再检查和发送提醒；已经填写的日期、时间和话术继续保留，再次开启时恢复。 |
| 日常下单日期 | 星期多选 | 开启催单时必填；批量设置默认周一至周五 | 至少选择一天，否则阻止保存并提示“请至少选择一个日常下单日期”。 |
| 提醒时间 | 时间选择器 | 开启催单时必填；批量设置默认16:30 | 按北京时间、精确到分钟执行；未填写时阻止保存并提示“请设置提醒时间”。当天提醒时间已过时，不补发当天提醒。 |
| 催单话术 | 多行文本框 | 开启催单时必填；默认使用页面预置话术 | 去除首尾空格后为1～200个用户可见字符，允许换行和表情符号。为空提示“请输入催单话术”，超过200个字符提示“催单话术不能超过200个字符”。 |

## 4. 业务逻辑

### 4.1 设置生效规则

1. 单群保存只更新当前群聊；批量保存使用同一组设置覆盖所有已勾选群聊，未勾选群聊不受影响。
2. 批量保存后仍可单独修改某一群聊，以该群聊最后一次成功保存的设置为准。
3. 提醒时间前修改设置，当天按新设置执行；提醒时间后启用或修改，当天不补发，从下一个符合条件的日期开始执行。
4. 关闭催单后立即停止后续检查和提醒，但保留原日期、时间和话术。
5. 催单配置以群聊唯一标识关联；群聊改名不丢失配置。

### 4.2 自动催单流程

1. 到达群聊设置的提醒时间后，系统先确认催单已启用，并确认当天属于该群聊选择的日常下单日期。
2. 为避免大量群聊同时发送消息，系统为每个“群聊 + 日期”的催单任务生成一次固定时间的随机延迟，实际执行时间为“提醒时间 + 随机延迟”。该延迟为系统内置规则，不在页面展示，也不允许用户配置。
3. 随机延迟只在任务首次生成时计算；任务重试沿用原执行时间，不得重新随机导致持续后移。
4. 到达实际执行时间后，系统再次查询该群聊当天零点至当前时刻是否已经产生有效销售订单；延迟期间已下单则取消本次催单。
5. 已下单：不发送催单消息，记录“已下单，无需提醒”。
6. 未下单：机器人在该群聊发送已保存的催单话术，并记录发送结果。
7. 同一群聊同一天最多成功发送一次。即使检查任务重复或同时执行，也不能产生第二条成功提醒。
8. 提醒后客户再下单，不撤回已经发送的消息，当天也不再次提醒。

## 5. 操作与异常

- 进入批量选择：点击“批量设置催单”后显示复选框和批量操作栏；可自由勾选或取消任意群聊；点击表头“全选”选择当前搜索结果，再次点击取消这些可见群聊；点击“取消”退出选择态并清空全部勾选。
- 批量设置：未选择群聊时按钮置灰；保存成功后退出选择态并提示“已批量保存 {{群聊数量}} 个群聊的催单设置”。
- 单群修改：可从列表催单列的“设置”或详情页签进入；回显当前配置，成功后仅更新该群聊并提示“群聊催单设置已保存”。
- 保存失败：弹窗保持打开并保留输入，展示具体失败原因。
- 订单查询失败：不发送，避免误催；记录失败原因并按任务策略重试。
- 信道离线、群聊停用或机器人无发言权限：不发送并记录原因。
- 说明模式：群聊列表和群聊详情共用顶部“业务说明”入口；点击后只进入说明模式，不自动打开侧边栏；选择页面元素后才展示对应说明，关闭侧边栏后可继续选择其他元素。
- 功能归属：销售订单“设置”仅保留信道设置、通知设置、回复设置和功能设置，不展示催单设置入口。

## 6. 验收标准

1. 到达随机延迟后的实际执行时间且群聊当天未下单时，机器人只发送一次配置话术。
2. 提醒时间前或随机延迟期间已存在有效订单时，不发送催单消息。
3. 批量保存只更新已选群聊，未选群聊保持不变；单群后续修改只影响当前群聊。
4. 开启催单但缺少日期、时间或话术时，系统阻止保存并显示对应文案。
5. 话术包含中文和表情符号且不超过200个字符时可完整保存；第201个字符不得提交。
6. 群聊名称发生变化后，原催单设置仍然保留并继续生效。
7. 点击“业务说明”进入说明模式时，右侧说明栏默认关闭且页面元素均可点击；点击具体元素后才打开说明栏，关闭说明栏后仍停留在说明模式，退出后恢复原交互。
8. 同一提醒时间存在大量待发送群聊时，各群聊实际发送时间应分散在提醒时间后的 0～15 分钟内；页面不得出现随机延迟配置字段。
9. 批量选择态支持逐项多选和表头全选；搜索后全选只影响当前可见结果，搜索前已勾选的其他群聊保持选中。
