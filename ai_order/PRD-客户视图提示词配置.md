# 客户视图提示词配置需求

版本：V1.0  
日期：2026-08-14  
适用页面：销售录单 / 提示词 / 客户视图

## 1. 背景与目标

现有客户视图只展示已配置客户，运营无法发现漏配客户；“未配置”和“启用模板”也容易混淆系统提示词、客户专属提示词和绑定数量。

本次目标是以全部正常启用客户为检查基线，分层呈现系统基础配置与客户专属配置，并保留统一的模板管理流程。

## 2. 范围

本期包含客户视图列表、筛选、空状态、右侧详情抽屉，以及跳转至客户提示词管理的联动。

本期不包含停用客户展示、停用模板历史、历史配置审计和客户视图内编辑。

## 3. 核心口径

- 客户范围：只展示当前租户中状态为“正常启用”的客户；无客户专属提示词也必须展示。
- 当前配置：只统计启用模板与客户之间的有效绑定；停用模板不计入。
- 已配置客户：至少存在 1 条启用的客户提示词绑定。
- 未配置客户：不存在启用的客户提示词绑定，不代表系统提示词未生效。
- 启用绑定：启用模板与客户的有效绑定关系数，不等同于模板去重数。
- 最近更新：该客户启用绑定中的最大更新时间；无启用绑定显示“—”。

## 4. 页面结构与字段

保持现有“列表 + 右侧抽屉”结构，不增加行内编辑。

顶部统计：

- “正常启用客户”：当前列表基础数据总量。
- “启用绑定”：全部正常启用客户的有效启用绑定总数。

筛选区：

- 搜索：支持客户名称、客户 ID、关联群聊名称、启用提示词名称或内容摘要。
- 提示词类型：全部 / 订单解析 / 意图识别。
- 配置状态：全部 / 已配置 / 未配置。
- 多条件按交集生效。

列表字段：

| 字段 | 展示规则 |
|---|---|
| 客户 | 头像简称 + 客户名称 |
| 关联群聊 | 一个群聊直接展示；多个群聊展示首个名称和“+N”；无关联显示“未关联群聊” |
| 订单解析提示词 | 只展示启用绑定；最多展示 2 个提示词，超出部分显示“+N”；没有时显示“未配置客户提示词” |
| 意图识别提示词 | 只展示启用绑定；最多展示 2 个提示词，超出部分显示“+N”；没有时显示“未配置客户提示词” |
| 启用绑定数 | 当前客户两类启用绑定数量之和 |
| 最近更新 | 启用绑定的最近更新时间；无绑定显示“—” |
| 操作 | 只提供“查看”，打开右侧详情抽屉 |

## 5. 右侧详情抽屉

抽屉按以下三层顺序展示：

1. 客户信息：客户名称、全部关联群聊；不展示客户 ID。
2. 系统基础配置：只展示订单解析、意图识别的配置状态，并提供“查看系统提示词”；不展示更新时间。任一系统提示词为空时显示“系统基础提示词未配置”警告，不得标为正常。
3. 客户专属配置：只展示启用模板的名称和类型，不展示内容摘要及更新时间。无启用绑定时显示“未配置客户提示词，当前仅使用系统基础配置”。

抽屉底部提供“管理该客户提示词”，不复制新建或编辑表单。

## 6. 联动与交互

点击“管理该客户提示词”后：

1. 关闭详情抽屉。
2. 激活“客户提示词”页签。
3. 将客户 ID 写入搜索条件并按该客户的绑定结果过滤。
4. 后续继续使用统一的新建、编辑、启停和客户绑定流程。

搜索或筛选无结果时展示明确空状态，并提供“清除筛选”；清除后恢复空搜索词、提示词类型“全部”、配置状态“全部”。

## 7. 异常与边界

- 无客户专属提示词：客户仍展示，启用绑定数为 0，详情说明仅使用系统基础配置。
- 系统提示词为空：显示警告，不得以客户专属提示词存在为由掩盖。
- 提示词停用：立即从客户当前配置、数量和筛选结果中移除；历史查看本期不做。
- 多群聊：列表必须显示“+N”，详情必须展示完整群聊集合。
- 客户停用：默认列表不展示；历史配置审计列为后续能力。

## 8. 验收标准

- 列表包含全部正常启用客户，并至少覆盖有配置、无配置、多群聊、无群聊四类样例。
- 无专属提示词时，两类提示词列均使用“未配置客户提示词”，绑定数为 0。
- 顶部使用“启用绑定”，统计值等于列表客户启用绑定数之和。
- 提示词类型和配置状态筛选项完整且可与搜索组合使用。
- 多群聊列表显示首个名称和“+N”，抽屉展示全部群聊。
- 列表不展示客户 ID；两类提示词字段均最多展示 2 个，超出部分以“+N”表示。
- 抽屉三层信息完整；系统提示词为空时能显示警告。
- 抽屉不展示客户 ID、系统配置更新时间、客户专属提示词摘要及更新时间。
- “管理该客户提示词”能切换页签并自动按客户 ID 筛选。
- 搜索无结果时可一键清除筛选并恢复完整客户列表。
