# 图框联动识别第一期 PRD

| 项目 | 内容 |
|---|---|
| 适用端 | 租户端 |
| 适用页面 | 功能设置、订单审核列表、订单审核详情 |
| 版本 | V1.1（原型评审版） |
| 日期 | 2026-07-15 |

## 1. 背景与目标

图片订单进入审核后，操作员需要反复对照采购单原图和 AI 识别商品。第一期增加“图框联动识别”，建立原图标注框与商品行的关联，实现：

- 点击商品定位原图；
- 点击原图定位商品；
- 商品修改、排序、删除后来源关系仍可追溯；
- 合单商品可切换查看多个来源；
- 定位能力不影响编辑、保存和下单。

## 2. 用户与生效条件

### 租户管理员

- 开启或关闭功能；
- 配置生效群聊和客户；
- 保存配置。

### 操作员

- 在订单审核详情页使用原图定位；
- 编辑、排序、新增或删除商品；
- 查看合单商品的多个来源。

### 生效条件

```text
租户已获得功能权益
+ 图框联动识别开关开启
+ 订单命中已选群聊或客户
= 当前订单启用图框联动识别
```

Superadmin 授权链沿用现有能力，不在本 PRD 展开。

## 3. 本期范围

### 包含

- 租户功能开关及群聊、客户生效范围；
- 原图标注框展示；
- 图文双向定位；
- 人工修改、手动排序后保留来源；
- 人工新增商品无来源；
- 删除商品后保留来源框；
- 合单商品双来源切换；
- 上一条、下一条逐条巡检及人工漏单核对；
- 定位异常时降级为普通审核。

### 不包含

- 新增“AI 重新识别”按钮，继续使用现有“重识别”；
- 复制商品来源状态；
- 跨分组移动状态及提示；
- 来源状态字段、修改历史图标或追溯弹窗；
- 标注框内文字；
- 独立“定位来源”标签页；
- 来源说明栏及“模拟定位失败”按钮；
- 漏品、错行检测及其他标框算法；
- 通用多图、图片旋转、倾斜适配；
- 商品拆分或人工绑定原图来源。

## 4. 功能设置

路径：`设置—功能设置`。

页面只保留：

```text
[开关] 图框联动识别
群聊生效范围 | 客户生效范围
[保存]
```

规则：

- 开启后展示群聊、客户选择区域；
- 关闭后隐藏选择区域；
- 支持搜索添加、移除群聊和客户；
- 群聊和客户分别支持全选，再次点击可清空该类选择；
- 不展示功能说明、状态说明和规则说明等小字。

## 5. 订单审核列表

原型“业务场景”列集中演示：

- 单商品原图联动；
- 人工修改后保留来源；
- 手动排序后保留来源；
- 人工新增商品无来源；
- 合单商品双来源切换；
- 已删除商品来源保留；
- 标记区域人工核对漏单；
- 普通订单审核。

该列用于原型评审，不要求新增正式订单状态字段。点击“查看”进入审核详情。

## 6. 订单审核详情

### 6.1 页面结构

页面保持左右布局：

- 左侧：基本信息、群聊消息、采购单原图；
- 右侧：订单信息和商品编辑表格。

左侧只有两个标签单元：

1. 基本信息；
2. 群聊消息＋定位来源。

默认选中“基本信息”。“图框联动识别”位于首行，采购单图片直接展示在该标签页内。

### 6.2 精简项

详情页不展示：

- 任务标题旁的“原图联动审核”；
- 订单分组下方的业务场景标签条；
- 订单备注右侧的删除说明；
- 商品修改历史图标；
- 独立定位来源标签页；
- 来源说明栏、模拟定位失败按钮；
- 分组变更、稳定商品 ID 提示。

## 7. 原图标注框

| 场景 | 表现 |
|---|---|
| 默认来源 | 左侧显示蓝色半透明色块，不显示边框 |
| 当前定位 | 左侧对应色块保持蓝色并增加白色边框，同时自动放大居中；右侧商品行显示蓝白呼吸渐变 |
| 商品已删除 | 来源框保留，仍使用蓝色色块，不出现红色 |
| Hover | 左侧色块轻量加深，不触发滚动；未选中的右侧商品行保持白色 |

通用要求：

- 标注框内不显示文字；
- 点击左侧标注或右侧商品时，右侧对应商品行显示蓝白呼吸渐变；未选择商品时保持默认白色；
- 商品修改不额外产生颜色、边框或标签状态；
- 鼠标位于原图区域时支持滚轮缩放，并以鼠标所在位置为缩放中心；
- 按住原图中的非识别区域可以左右或上下拖动查看，拖动识别色块仍执行商品联动；
- 橙色只表示当前操作焦点；取消选中后恢复灰色或蓝色业务状态；
- 呼吸动效保持缓慢、低干扰，并兼容系统“减少动态效果”设置；
- 标注框不得遮挡主要原图内容；
- 页面可同时展示多个标注框；
- 图片超出区域时允许滚动查看。

## 8. 图文双向定位

### 商品定位原图

点击右侧有来源的商品行后：

- 左侧显示对应来源图片；
- 对应标注框进入当前定位状态；
- 图片自动滚动到可视位置；
- 商品保持可编辑。

### 原图定位商品

点击左侧标注框后：

- 展开对应订单分组；
- 商品行滚动到可视位置并短暂高亮；
- 不自动进入输入框编辑状态。

### 逐条巡检

原图上方提供“上一条、下一条”：

- 按原图标注框从上到下、同一行从左到右的顺序切换；
- 每次切换同时定位左侧标注框和右侧商品行；
- 顺序以原图标注为准，不受右侧人工排序影响；
- 合单商品按主来源占一个巡检位置，其他来源通过“来源 1/2”切换；
- 已删除商品仍进入巡检，提示“对应商品已删除”；
- 只有标注框、没有对应商品的区域仍进入巡检，提示“该原图区域暂无对应商品，请核对是否漏单”。

漏单判断由操作员完成，第一期不增加自动漏单结论。

### 无来源商品

人工新增商品不生成标注框。点击该商品时，左侧保持不变，可提示“人工新增商品无原图来源”。

## 9. 默认顺序与人工排序

启用本功能的订单：

- 同一订单分组内，右侧商品默认顺序与左侧标注框识别顺序一致；
- 合单商品按主来源顺序确定默认位置；
- 人工新增商品追加在当前分组末尾；
- 操作员可以调整右侧商品顺序；
- 人工排序只改变展示顺序，不改变商品标识、标注框位置和来源关联；
- 排序后仍支持双向定位。

## 10. 编辑、新增与删除

核心规则：商品内容可以变化，原图来源关系不因普通编辑而丢失。

| 操作 | 来源处理 |
|---|---|
| 修改名称、SKU、数量、单位、单价、备注 | 保留来源，标注框变蓝 |
| 手动排序 | 保留来源 |
| 人工新增 | 无来源，追加到分组末尾 |
| 删除商品 | 右侧隐藏，左侧来源框保留 |
| 合单商品 | 保留多个来源 |

新增、删除商品条目采用静默操作：

- 新增后直接插入商品行，不弹提示；
- 删除时不弹操作提示；
- 删除后点击左侧来源框，提示“对应商品已删除”。

页面不新增来源状态列，原图框内也不显示修改或删除文字。

## 11. 合单商品多来源

同一商户的不同销售订单合单后，相同商品可能合并为一行。例如：

```text
销售订单 A：商品 2 袋
销售订单 B：商品 3 袋
合单结果：商品 5 袋
```

交互规则：

- 右侧只显示一条合单商品；
- 默认定位来源 1；
- 左侧提供“来源 1、来源 2”切换；
- 两个来源框都定位到同一商品行；
- 修改商品后两个来源仍保留；
- 删除商品后两个来源框仍保留，点击提示商品已删除。

第一期只处理合单产生的多来源。

## 12. 商品表格规范

保留字段：序号、识别文本、商品名称、数量／单位、单价、总价、备注、SPU 名称、操作。

- 数量输入框与单位不得重叠；
- 货币符号与单价输入框不得重叠；
- 宽度不足时允许横向滚动；
- 不展示来源状态列和修改历史图标。

## 13. 异常与降级

以下情况不得阻断审核：

- 订单没有定位数据；
- 商品没有来源数据；
- 标注坐标异常；
- 原图加载失败；
- 来源与商品无法匹配；
- 订单未命中功能范围。

降级后仍可编辑、保存和确认下单，不自动将整个订单标记为失败。页面不提供人工模拟失败入口。

## 14. 数据规则

- 商品与来源基于稳定商品标识关联，不使用页面行号；
- 初始商品顺序与标注顺序一致；
- 上一条、下一条固定按原图标注顺序巡检；
- 人工排序不改变来源关联；
- 商品修改不改变原始图片；
- 删除商品保留来源关系和删除标记；
- 合单商品允许关联多个来源；
- 人工新增商品没有来源；
- 现有“重识别”沿用原流程，可生成新的识别结果和来源版本。

### 功能设置

- [ ] 开关开启后展示群聊、客户范围，关闭后隐藏；

- [ ] 人工排序后巡检顺序仍以原图为准；
- [ ] 无对应商品的标注区域可进入巡检并提示人工核对漏单；
- [ ] 无来源商品不生成标注框。

### 顺序与编辑

- [ ] 初始商品顺序与标注顺序一致；
- [ ] 人工排序后来源关联不变；
- [ ] 修改商品后来源保留；
- [ ] 新增、删除商品时不弹提示；
- [ ] 删除商品后来源框保留，点击提示商品已删除。

- [ ] 修改或删除后多个来源仍保留；
- [ ] 定位异常不影响编辑、保存和下单。
